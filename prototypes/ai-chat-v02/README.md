本轮交互变更供 HTML 原型打磨，不表示已移植到 WPF。正式应用 0.3.17 仅修复额外报告的 AI 圈点焦点黄框。

## 构建与文件

运行 `python prototypes/ai-chat-v02/build.py`。需要 XeLaTeX、dvisvgm、xeCJK 和 Microsoft YaHei。
`transcripts.json` 保存真实底稿、现编续答及只读文件快照；`template.html` 保存布局；`app.js` 保存交互；构建得到离线 `index.html`。
167 个不同公式一次编译，445 个 SVG 实例内嵌。中间产物在 artifacts/chat-prototype-v02-math，不提交。

## 本轮交互

- 1、10：发送时间与 34 px 操作按钮同排左对齐；答复收起时在上方追加答复时间，展开时在答复末尾左对齐。
- 2、4：每轮独立收起过程／全部，章节按标题层级折叠；保存折叠状态与阅读锚点、视窗偏移。切换与刷新恢复位置。
- 3、18：main.tex、qa.md 和行号链接打开收集的只读源码快照，目标行高亮居中；不操作正式项目。
- 5、6、11、17：行间公式上下留白减半；编号 Times New Roman；正文思源宋体 16 px；各级标题思源黑体；行内、行间公式统一 18.25 px。字体优先使用本机安装版本，其他设备缺失时使用系统后备字体。
- 7、8：关闭与新对话图标使用对齐的 SVG。
- 9、20：公式不是焦点／跳转目标。原位批注仅明确收起、Esc、打开其他面板或切换对话时关闭；滚动时跟随锚点，锚点移出视野时浮窗停靠阅读区并提示。
- 12、19：圈点保存选取时快照。发送记录保存原始 request 与显示摘要；成功后清空此次已发送圈点，失败或停止保留；未勾选的圈点保留。历史的已完成圈点迁入发送原件；显示摘要不绑定创作中的位置。
- 13：取消输入框顶部圈点刘海，访问级别右侧提供圈点数量按钮，打开独立编辑对话框。
- 14：原文默认一行省略，双击／Enter 展开收回，悬浮黄底黑字提示完整原文。PDF 保存原图快照。
- 15、16：多行编辑统一 Cascadia Code / Consolas、逻辑行号、自动折行、滚动同步、Tab 缩进。Enter 换行，Ctrl+Enter 发送；条目右下角提供单独发送按钮，主输入草稿不受单条发送影响。
- 21：原型 AI 圈点按钮使用明确的按下态，鼠标退出后不残留焦点框；正式 WPF 改用只针对键盘导航的 FocusVisualStyle。

## 数据及限制

保留原有五轮真实问答，以及香农熵、哈希与碰撞、泊松近似三段样例历史。每段样例均包含真实底稿和现编续答，明确标注来源。文件快照来自该对话对应的 hash 稀释项目，未采集账号或凭据。
原型不调用实时 AI；既有圈点使用预编摘要，新圈点使用主题规则／原文截取演示显示层。发送仍播放香农熵示例，不根据任意问题生成答案。正式接入时应以模型生成摘要替换该演示函数，request 中原始快照保持不变。
Ctrl+Alt+T 打开试验台；?test=1 使用独立存储。浏览器 localStorage 保存状态，省略可重建的 SVG HTML。恢复按钮恢复初始会话和样例；新版本追加样例仅执行一次，不覆盖用户草稿。
编辑器为原型 textarea，不是完整 AvalonEdit，未模拟多光标与语法补全。Markdown 解析器仅用于精选底稿。
