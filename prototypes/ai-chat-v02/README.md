# AI 对话实现基线 v0.2.1

本版以 TeXeed 0.3.16（b2e44b0）和用户 2026-10-16 提供的截图为基线。
上一版 v0.1 是提前提出的新交互方案，不能作为现有产品的原型；保留其历史文件，但当前本地预览入口改为本目录。
本版只提取现有实现，不修改或发布 WPF 应用。

## 打开

直接打开 index.html；HTML、TeX SVG、PDF 圈选缩略图全部内嵌，不依赖网络。
本地预览：http://127.0.0.1:8766/，服务根目录为本目录。
构建：在项目根运行 python prototypes/ai-chat-v02/build.py。
中间文件存入 artifacts/chat-prototype-v02-math，不加入源码快照。

默认显示真实会话的最新回答末尾和圈点列表底部，与截图的阅读位置相对应。
回答末尾保留公式 (39)、(40)、校对通过记录与 17:22:34 答复时间。

保留原有操作规则：

- 普通阅读不自动弹出新设计的选择工具条；右键菜单提供批注和复制。
- 开启应用外层的「AI 圈点」后，选择或单击回答段落，打开原位编辑器。
- 原位编辑器只有标题、编辑框、删除、收起自动保存，与底部条目共享内容。
- 待提交条目在原文留下编号；提交中和已完成时隐藏气泡。
- 已完成条目仍在底部列表，取消勾选；通过原有菜单清理。
- 上下文在每个条目内展开；PDF 显示实际收集的圈选缩略图。
- Enter / Shift+Enter 换行，Ctrl+Enter 发送。
- 不加入 v0.1 的场景侧栏、段落加号、精简批注芯片、单条立即追问或双向跳转按钮。

## Transcript 与试验操作

transcripts.json 只读采集截图所示会话的 5 轮真实问答、7 个条目、关联源码片段和 4 张 PDF 圈选缩略图。
没有采集凭据或账号资料；没有改写正式会话。保留活动标题和时间，省略工具详情。
历史菜单新增 v0.1 已构造的香农熵、哈希与碰撞、泊松近似三段聊天，每段包括真实底稿与现编续答，标题和活动记录明确标为原型样例。
首次升级只追加这些样例，保留当前会话、圈点和草稿；再次刷新不重复添加，用户删除的样例不会自动恢复。
发送回放仍沿用明确标记的香农熵样例，仅用于播放发送与校对状态，不是实时 AI。

Ctrl+Alt+T 打开独立的原型试验台，也可使用 ?tools=1。
其中可模拟应用外层的 AI 圈点开关、选择成功／校对／失败回放、恢复截图状态、查看和导出 transcript。
这些控件不放进产品面板，避免混淆现有设计。

原型仅在浏览器 localStorage 保存试用状态；?test=1 使用独立测试存储。
保存时省略可从内嵌 transcript 重建的 SVG HTML，避免样例公式占满浏览器存储；刷新时恢复公式及其批注定位。
账号登录、API Key、联网模型列表、项目文件操作未接入；相关设置页明确标识未连接。
模型只列出截图中可确认的一项，不虚构账号可用模型。
此处 Markdown 转换器服务于精选 transcript，不替代正式应用的通用 Markdown 引擎。
WPF 与浏览器文字测量、选择和系统菜单仍会有平台差异；本版用于核对结构及已实现交互，不声称像素级一致。

- 166 个不同公式由 XeLaTeX 批量编译成功，438 个实例嵌入 SVG。
- JavaScript 语法检查通过。
- 浏览器验证：右键批注、气泡重开、原位／条目同步、完成后气泡隐藏且条目保留并取消勾选、外层圈点开关。
- 核对独立滚动：上下文列表最大 170 px、输入栏 66 px，回答区占用剩余高度。
- 按截图对应的 849 × 1001 逻辑尺寸核对布局，并恢复浏览器正常尺寸。

- v0.2.1 浏览器验证：旧会话及其回放与批注保留；三段样例进入历史；按续答正文搜索；切换后完整显示两轮问答；刷新后草稿、SVG 恢复且样例不重复；无控制台错误。
