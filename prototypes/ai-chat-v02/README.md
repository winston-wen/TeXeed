# AI 对话原型 v0.4

- 显示公式编号改为 Times 字体的 `Eq. n` 圆角框。转为行内的公式保留内部编号锚点，不为隐藏编号重排后续编号，避免旧引用失效。
- 已发送问题和圈点摘要使用仿宋＋Cormorant Garamond Italic；拉丁字符使用内嵌斜体字体，中文不合成倾斜。编辑器字体保持不变。
- 当本轮问题完全滚出视野且阅读区域总高至少 420 px 时，顶端显示两行提示：首个非空问题行、前三个圈点摘要。提示单独占据 61 px，由亮线分隔，不覆盖答复。短窗口自动隐藏。
- 发送时间左沿与过程开关对齐。新对话图标使用半径 9、中心 (10,10) 的圆形气泡，嘴尖位于外接矩形左下角 (1,19)，加号居中，与相邻 20×20 图标的轮廓边缘对齐。
- 顶栏默认隐藏，小刘海单击展开／收起；展开后双击固定／解除固定。固定按钮为金色，自动模式为灰色；固定状态持久保存。自动模式离开顶栏或点击阅读区后收起，键盘焦点操作保留可访问性。
- 所有原型标题最多 20 个 Unicode 字符；标题字号 16 px、常规字重，与正文相同。原会话标题整理为“哈希、熵与随机映射”。
- 不含等号／等价关系且 SVG 实际宽度不超过五个正文字号的短公式并入相邻句子；原始 transcript 不变，旧批注锚点映射到合并后的段落。
- 提供最小熵长段落展示样例，以及可点击的 Eq. 7、Eq. 8 引用；跳转会展开目标所在章节并短暂高亮，点击公式本身不跳转。

`prompts.json` 保存标题和答复排版提示词，并嵌入原型发送记录的 request。提示词要求标题不超过 20 字、连贯长段落、短公式行内化，以及 label/eqref 引用。原型仍没有实时模型调用；正式应用的提示词尚未改动。长段落展示样例单独存于 readingEdits，真实历史原文和“复制这段回答”的原始源码保留。

字体来自 [Google Fonts 的 Cormorant Garamond 目录](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond)，未修改的字体和 OFL 许可证位于 fonts/；构建时内嵌到 index.html，离线不发起字体请求。仿宋使用本机字体，未安装时回退 serif。

## 数据及限制

保留原有五轮真实问答，以及香农熵、哈希与碰撞、泊松近似三段样例历史。每段样例均包含真实底稿和现编续答，明确标注来源。文件快照来自该对话对应的 hash 稀释项目，未采集账号或凭据。
原型不调用实时 AI；既有圈点使用预编摘要，新圈点使用主题规则／原文截取演示显示层。发送仍播放香农熵示例，不根据任意问题生成答案。正式接入时应以模型生成摘要替换该演示函数，request 中原始快照保持不变。
Ctrl+Alt+T 打开试验台；?test=1 使用独立存储。浏览器 localStorage 保存状态，省略可重建的 SVG HTML。恢复按钮恢复初始会话和样例；新版本追加样例仅执行一次，不覆盖用户草稿。
编辑器为原型 textarea，不是完整 AvalonEdit，未模拟多光标与语法补全。Markdown 解析器仅用于精选底稿。
