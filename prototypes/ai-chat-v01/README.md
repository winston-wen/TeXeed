# AI 对话交互草稿 v0.1

第一轮聚焦：阅读回答 → 圈点 → 原位批注 → 合并追问 → 回到原文。
这是独立的设计原型，不修改 TeXeed 正式程序或已保存的会话。

## 打开与修改

直接用浏览器打开 index.html，全部内容与公式均已内嵌，无网络或模型服务依赖。
开发时可在此目录运行 Python 的 http.server，仅绑定 127.0.0.1。

- template.html：交互、布局和样式。
- transcripts.json：三段收集的真实问答、三段现编续答、示例批注、校对状态及交互脚本。
- build.py：将精选 transcript 排版，并生成 index.html。
- index.html：可直接打开的完整交付文件。

在项目根目录运行：python prototypes/ai-chat-v01/build.py。
构建使用本机 XeLaTeX、xeCJK、Microsoft YaHei 和 dvisvgm，将 104 个不同公式合并到同一 TeX 文档，逐页转换 SVG。
中间文件只写入 artifacts/chat-prototype-math。
此处 Markdown 解析器只覆盖这些精选底稿用到的格式，不用作正式产品的通用解析器。

## 内容来源

按用户要求，从本机 TeXeed 已有会话中收集：

1. 讲解香农熵。
2. 哈希映射、碰撞与泊松原像模型的三个问题。
3. 推导二项分布到泊松分布的极限。

只保留问题与回答，未收集凭据、模型配置、项目绝对路径或工具输出。
真实底稿保留原文；续答、示例批注和失败过程均为本轮编写，有清楚标记。
原型发送任何新问题，都播放该场景的预编续答，不调用实时 AI。
正式产品的编译与校对状态在此以预编事件演示；底稿 SVG 已实际编译。

## 本轮可讨论的选择

- 普通阅读时选中文字，出现批注与复制入口；打开圈点模式后，选中直接写批注。
- 公式可以单击后批注，也有键盘入口；段落右边的 ＋ 可批注整段。
- 批注自动保存，原位编号与底部精简条目共享一份草稿。
- “继续阅读”收起编辑器；“只问这一处”发送单条，其他草稿保留。
- 可在底部合并发送几处批注，并附一段统一问题。
- 已发送编号保留为空心气泡；发送快照不可改，可重新引用继续问。
- 续答的批注引用可跳回原文，并能返回追问位置。
- 请求失败时保留问题，支持原轮重试或放回草稿。
- 浏览器刷新恢复草稿与演示轮次；运行中的演示标成已停止。
- 通过“Transcript”查看真实来源、现编内容、本次交互事件，并导出 JSON。

本机试用记录只写入该页面来源的 localStorage；不写回 TeXeed 会话。
URL 加 ?test=1 使用独立的测试存储，避免测试问题出现在正式试用中。
