# TeXeed

原生 Windows LaTeX 编辑器，使用 **C# / .NET 10 / WPF**，编辑器基于 AvalonEdit，PDF 使用本机 PDFium 渲染。

## 运行

发行目录内直接运行 `TeXeed.exe`。也可以把主 `.tex` 文件拖到窗口，或以命令行参数传入：

```powershell
.\TeXeed.exe "D:\Documents\My paper\main.tex"
```

源代码开发需要 Windows 10/11 x64 和 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)：

```powershell
dotnet restore TeXeed.slnx
dotnet run --project src/TeXeed.App
```

编译 LaTeX 需要另行安装 [TeX Live](https://www.tug.org/texlive/windows.html) 或 [MiKTeX](https://miktex.org/download)。从标题栏菜单（窄窗口使用菜单按钮）进入“排版 → 设置”，检测引擎或指定可执行文件。支持 `latexmk`、XeLaTeX、pdfLaTeX、LuaLaTeX，以及 [Tectonic](https://tectonic-typesetting.github.io/)。中文项目建议使用 XeLaTeX 和 `ctex`。TeX 发行版及宏包未包含在应用发行包中。

## AI 问答（0.3.0）

标题栏 AI / Alt+A 打开 AI tab。支持 ChatGPT 浏览器登录、API Key 备用、源码与 PDF 跨页选区、问题条目批量提交和只读源码检索。操作与登录说明见 [AI 工作区](docs/ai-workspace.md)。

## 工作方式

- 默认项目名为主文件所在目录名。打开项目后，在“排版 → 设置”填写项目名称，或点击“使用 `\title`”从主文件标题提取；清空则恢复目录名。名称存于项目的 `.texeed/project.json`，不会改变主文件名或编译产物名。
- 视图 → 主题：内置 One Dark Pro Ristretto（默认，保留现有暖棕配色）和 GitHub Light Default（取自本机 VS Code GitHub Theme 6.3.5）。切换立即生效并保存；标题栏、编辑区、语法高亮、大纲、菜单、设置及滚动条同步换色。切换主题时 PDF 采用对应的深色／原色模式，仍可用“反色”单独调整。
- PDF 默认反色预览：采用 Ristretto 暖棕黑纸张（#2C2525）和柔和米白文字（#D8CCC8），文字边缘、中间灰阶及图片颜色同步映射。预览 tab 的齿轮设置或应用设置中的“反色”选项可以恢复原色，选择跨版本保存。只处理显示图像，不改变 PDF 文件或导出颜色；切换时保留已有画面，恢复原色从 PDF 重新渲染，反复切换不累积色差，缩放、SyncTeX 定位和阅读位置不受影响。
- 深色主题的编辑区正文、选中文字与补全列表采用柔和米白（#D8CCC8）；浅色主题采用 GitHub 的深灰正文。滚动条参考 VS Code 编辑器：纵向宽 14 DIP、横向高 12 DIP，使用半透明主题色与小圆角矩形。区域内鼠标／键盘操作或滚动时显示，静止 500ms 后以 800ms 淡出；悬停滚动条或拖动期间保持显示。隐藏不改变排版宽度。PDF 滚动条覆盖在页面外侧留白上，适合宽度时以整个预览区居中，两侧留白对称。
- 编辑区和预览区各有独立底条：编辑区显示编译状态、行列和文件格式，通过“展开输出／收起输出”切换编译输出；预览区显示页数和状态。左栏没有底条，项目统计可悬停面板标题查看。分隔线仅一条 2 DIP，8 DIP 拖动命中区在悬停／拖动时半透明亮起。行为依据和实现说明见 [界面交互说明](docs/ui-chrome.md)。
- PDF 默认开启自动裁边：横向依据文档类及 `geometry` 等设置最终生效的正文版心，保留约 6 pt 安全留白，支持奇偶页边距和中途调整边距；短行、段落缩进、居中表格或越界内容均不改变横向裁量。纵向按实际内容裁去上下白边；独立的“压缩纵向空白”选项默认开启，进一步压缩跨整页宽度、超过 36 pt 的空白，页码、图表及普通行距保留，图片和矢量图块内部的留白不会压缩。关闭压缩保留正文内部原始间距；关闭自动裁边会禁用压缩控件，但保留其偏好。按裁后版心适合宽度、多页连续滚动，支持手动缩放、调整窗口与 SyncTeX 双向定位。预览 tab 的齿轮设置或应用设置可以关闭并保存偏好；源文件及导出的完整 PDF 不变。读取不到有效版心信息时保留整页宽度；空白页保留纵向尺寸。实现与兼容范围见 [PDF 裁边说明](docs/pdf-cropping.md)。
- 大纲标题保留 LaTeX 文字样式；`$…$`、`\(…\)`、`\[…\]` 中的公式用 WpfMath 排版为原生矢量图，支持求和、上下标、分式、根号和矩阵。公式等比缩小到最多 24 DIP 高，保持单行；缓存矢量结果，不触发文档编译。未知命令或不支持的公式保留源文字，不执行用户宏定义。
- 打开主文件，递归加载 `\input`、`\include`、`\subfile`、`\import`、`\subimport`、文献数据库、本地样式和图片资源。文件树展示发现的依赖，文件标签保留编辑状态和撤销历史。
- 项目读取与首次索引在后台准备；侧栏、标签引用和补全按文件复用索引，只重新解析内容或元数据发生变化的文件。无改动的侧栏切换不重复扫描全书或重建大纲；项目文件复用现有树并按可见区域排版，保留折叠和选择状态。
- 开启“实时预览”后，修改经过可配置的延迟，**自动保存全部修改并编译**。关闭后可手动保存、编译。编译在后台进行，失败时保留上次成功的预览。
- XeLaTeX、pdfLaTeX 和 LuaLaTeX 按辅助文件变化和引擎提示决定是否补跑；引用稳定的普通正文修改通常只编译一遍。文献输入未变时复用 BibTeX/Biber 结果，引用、目录或文献改变时自动补齐所需步骤。编译过程中重复保存同一版本会合并，新修改按剩余防抖时间接续编译。
- 编辑器提供 LaTeX/BibTeX 高亮、行号、查找替换、注释、缩进、保守格式化、命令片段和上下文补全。`\ref`、`\eqref`、`\cite` 等补全来自整个项目，包含尚未保存的编辑。
- 按住 Alt 并用左键单击可在不同行列添加多个光标；Alt+左键拖动或中键拖动可进行列框选。输入、粘贴、删除和换行应用到所有光标，一次操作可整体撤销；Esc 或普通单击返回单光标。
- 字体可以在设置中任意选择。编辑区保留所选字体的字形，按固定网格排版：英文及窄字符一格、中文及宽字符两格，Tab 对齐缩进停靠点；光标、选区与命中测试使用同一网格，不修改文档中的字符。
- 编辑区复用已经排版的字形，降低滚动和大纲跳转时的重绘开销。缓存区分字体、字号、颜色、装饰及 DPI，并限制保留数量。
- 编辑区默认自动换行，长行按可见宽度折为多行显示，窗口变宽时自动重新排版。视图 → 自动换行或 Alt+Z 可开关，设置自动保存；软换行不修改源文件、不增加源码行号，也不影响撤销记录。
- “跟随视图”在源码滚到顶部时定位当前文件开头，并从对应 PDF 页的页首显示，子文件的章节标题不会被挤出视野；离开顶部后恢复按视图中央跟随。兼容 TeX Live 在中文路径下生成的系统编码 SyncTeX 文件。
- Ctrl+H 展开当前文件的替换栏，可替换当前匹配或全部替换，支持大小写、全词及正则选项。普通模式按原文插入替换内容；正则模式支持 `$1`、`${name}` 等捕获组。一次全部替换可用一次 Ctrl+Z 撤销。
- PDF 可以缩放、适合宽度、导出。预览齿轮设置和应用设置中的跟随模式提供三种选择：**不跟随**、**跟随光标**、**跟随视图**。跟随光标时，对应文字框垂直居中，文档首尾也可居中；跟随视图随源码滚动定位到可见内容的中间位置；编辑器支持文末超额滚动，末行可滚至视口中央或上方，中心落入文末留白时保持定位到末行。默认使用此模式。切换立即生效并保存，下次启动会恢复；所有模式下 Ctrl+J 都可手动定位到光标。Ctrl+滚轮缩放以鼠标下的 PDF 内容为中心，预览设置中的缩放和自动宽度保留视口中心的内容。PDF 上**右键双击**或 **Ctrl+左键**返回对应源码。视图跟随优先读取缓存的 SyncTeX 正文记录，排除沿用后续源码行号的分页框、规则线及定位间距，避免跨页时跳回上一页。其他定位及不支持的映射使用发行版 `synctex.exe` 与内置读取器互相补充。
- 左侧有大纲、文件树、全文搜索、书签、标签与引用和 TODO/FIXME 待办。书签沿用原标签形状图标，读取源码中显式的 PDF 书签；标签改用锚图标，继续显示 `\label` 引用锚点。书签按层级显示，支持标题／目标标识搜索、全部展开／收起；搜索保留上级节点，清空或 Esc 恢复原折叠状态，单击折叠、双击跳转源码并按当前跟随模式同步预览。大纲、书签与项目文件标题右侧的双箭头分别用于全部展开、全部收起；批量折叠不跳转源码。项目文件支持按文件名搜索，不区分大小写，中文名称也可筛选；保留命中文件的所属目录，清空搜索或按 Esc 恢复完整文件树及原折叠状态。书签、文件名搜索与全文搜索各自保留输入。编译问题可点击跳转源码，完整日志可展开查看。
- 源码默认在左栏打开，已打开的文件在原栏激活。源码和预览 tab 可以拖到另一栏的标签栏或内容区域；空栏自动收起，剩余栏占满文档区。在单栏模式下，将 tab 拖到文档区左／右边缘可创建对应一栏，半透明高亮提示落点；Esc 或丢失鼠标捕获取消拖动。源码移栏保留未保存内容、文档对象、撤销、光标、选择和滚动位置；左右栏可以同时显示不同源码，保存与编译包含两边修改。`Ctrl+F4` 和批量关闭只关闭源码，预览始终保留。编辑标签按标题自然宽度显示圆角外形，选中只显示渐变边框，标题悬停、按下时不填充高亮背景：点击 × 或在编辑区按 Ctrl+F4 关闭当前标签；右键可全部关闭、关闭其他、关闭左侧／右侧标签。左键拖动调整顺序，边缘停留可自动滚动；标签溢出时用滚轮或两端双箭头浏览，边缘渐变提示隐藏内容，不显示滚动条。关闭标签保留本次项目会话中的未保存内容和撤销记录，重新打开可继续编辑，保存全部仍包含这些内容。滚动条和标签标题悬停时使用普通指针，按住约 400ms 后显示张开手掌，开始拖动后显示握紧手掌，松开或丢失鼠标捕获后恢复。两种抓握光标由应用自定义，随 Windows DPI 缩放，不修改系统指针设置；分隔线和窗口边缘使用尺寸调整光标。
- 大纲按标题层级显示为可折叠的树，灰色竖线标明缩进，圆角 h1、h2、h3 等标记表示层级。展开三角固定在行末右对齐，短标题用点虚线连接标题与三角；整行单击展开/收起、双击跳转源码。方向键浏览及展开/收起，Enter 跳转；编辑、保存或切换侧栏后保留折叠状态。
- 双击大纲标题居中定位源码并同步当前预览跟随模式，相邻或重复标题也重新定位；“不跟随”模式下预览保持不动。双击保留原来的展开状态，不因第一击改变层级。
- 大纲长标题显示省略号，公式按原矢量排版在右侧裁切，不把整个公式丢弃；展开按钮保持可见，不需要横向滚动。按住标题上的左键或右键约 0.4 秒，完整标题在原行内来回移动，直到显示末尾；松开或失去鼠标捕获恢复省略显示，左键长按松开不会折叠。悬停可查看完整标题、文件名和行号。光标所在章节显示笔图标，含 TODO/FIXME 的章节徽标显示红点；标记归到当前可见的最深层级。
- 左栏移除独立的折叠、全部展开和全部收起图标。大纲高亮跟随编辑区可见范围，同屏涉及多个章节时一起高亮；优先显示已展开的最深层级，收起分支由可见父标题代表，不自动展开。
- PDF 缩放、适合宽度和调整预览区大小时，保留现有页面图像并即时缩放，后台完成新分辨率渲染后再替换，避免先清空页面造成闪烁；连续缩放时丢弃过期结果。
- 自定义标题栏随主题换色，宽窗口始终显示主菜单和项目名，空间不足时合并为常驻菜单按钮；不显示左上角图标。窗口最小宽度为 280 DIP。最大化使用当前显示器的工作区，保证两侧底条可见；保留原生拖动、双击最大化和边缘缩放。Alt 激活或退出菜单焦点，不隐藏菜单栏；Alt+F/E/V/B/H 直接打开相应菜单，最小化恢复后菜单仍可见。
- F11 或“视图 → 全屏”进入／退出全屏，隐藏标题栏并使用当前显示器完整区域；显式通知 Windows 将任务栏置于激活的全屏窗口之后，Win 键仍由系统正常处理。退出恢复之前的窗口尺寸、位置和普通／最大化状态。进入、退出均显示淡入淡出的提示。全屏中单按 Alt 显示完整标题栏，可直接最小化、退出全屏或关闭窗口；再按 Alt、Esc 或点击内容区域收起标题栏，Alt+F/E/V/B/H 显示标题栏并打开对应菜单。
- 右键点击标题栏中主菜单／菜单按钮以外的区域，窗口菜单以鼠标点击处为左上角弹出；靠近屏幕边缘时 Windows 会避让屏幕边界。窄窗口的主菜单在同一面板逐层显示，多余内容可用滚动条或滚轮浏览；Esc 每次返回一级，根菜单上 Esc 关闭，点击菜单以外的区域全部关闭。顶部返回按钮或左方向键也可返回上一级。
- 大纲、文件、搜索、书签、标签和待办六个功能图标始终竖排在最左侧：单击关闭当前已展开的对应面板，单击其他功能或已关闭的面板则展开该功能。Ctrl+B 也可折叠/展开。保留之前的宽度和搜索内容，图标位置始终不变。设置、实时预览和停止编译保留在菜单中。
- PDF 预览作为标题为“预览”的 tab，与源码 tab 共用左右标签组；预览不能关闭，原关闭按钮改为齿轮。点击齿轮打开紧凑的预览设置，调整精确到两位小数的手动倍率、自动宽度、跟随模式、反色、裁边和纵向压缩。修改即时预览，“确定”保留，“取消”、Esc 或关闭窗口恢复打开时的设置。自动宽度的最大物理宽度默认 30 cm，可在 1–200 cm 内调整，实际宽度同时受预览栏空间限制；按当前显示器的 EDID 尺寸、分辨率、旋转和 Windows 缩放换算，不影响手动倍率。缺少物理尺寸时按系统 DPI 估算并在对话框注明。Ctrl+滚轮仍可直接缩放；导出 PDF 保留在文件菜单。
- 检测外部修改，保存前检查冲突，避免覆盖磁盘上的新内容。UTF-8 与带 BOM 的 UTF-8/UTF-16/UTF-32 文件保留原编码。无法安全识别的旧编码文件以只读资源显示。

## 主题文件

程序旁的 `Themes/*.json` 定义配色，格式说明见该目录内的 `README.md`。可以修改或复制文件创建自定义主题，再从“视图 → 主题”选择，或点击“重新加载当前主题”。主题选择与字体一样保存在用户设置里；文件内容只包含颜色，不执行脚本。

## 构建与验证

```powershell
dotnet build TeXeed.slnx -c Release
dotnet run --project tests/TeXeed.Tests -c Release
dotnet run --project tests/TeXeed.EditorTests -c Release
dotnet run --project tests/TeXeed.PdfTests -c Release
dotnet run --project tests/TeXeed.AppTests -c Release
.\scripts\publish.ps1
```

`TeXeed.Tests` 使用真正的子进程模拟引擎，验证编译参数、退出码、取消、旧 PDF 保留和 SyncTeX，同时检查项目解析、保存冲突、索引和格式化。编辑器与 PDF 测试在 Windows STA 线程上运行并加载实际控件/原生库。测试命令返回非零退出码表示失败；不依赖额外的测试框架。

`TeXeed.AppTests` 验证完整 WPF 窗口、多文件保存、异步保存期间的编辑保护、Alt 菜单、侧栏折叠及退出流程，并在 `artifacts/ui-check` 生成界面渲染图。菜单测试需要允许 WPF 获取键盘焦点与鼠标捕获的 Windows 桌面会话；可传入 `--close-only` 单独验证退出流程。如果工作区存在 `.tools/tectonic/tectonic.exe`，还会验证 Ctrl+S 实际编译、PDF 双向定位、视图跟随与自动保存预览；传入 `--viewport-only` 可单独检查视图跟随、手动定位、PDF 浏览/缩放取消同步和旧设置迁移。传入 `--build-scheduling-only` 可单独验证编译请求合并、剩余防抖、取消重试和项目切换。便携测试引擎及缓存不包含在发行包中。

大纲的专项界面检查可运行 `dotnet run --project tests/TeXeed.AppTests -c Release -- --outline-only`，验证层级竖线、折叠状态保留、标题跳转、键盘操作及窄侧栏和放大显示。

传入 `--themes-only` 可检查两套主题的即时切换、设置记忆、自定义 JSON、编辑状态保留及细圆头滚动条，并生成截图。

传入 `--titlebar-only` 可验证自定义标题栏的宽／窄布局、280 DIP 最小宽度、两套主题、三级菜单命令、滚轮浏览、逐层 Esc 和外部关闭，以及原生拖动／缩放命中、窗口菜单弹出坐标、最大化底部边界、F11／菜单全屏切换、窗口状态恢复和提示淡入淡出，并生成截图。`--workspace-only` 验证固定六图标栏、折叠／切换、预览齿轮设置及倍率输入；真实 PDF 缩放联动另由 `--viewport-only` 覆盖。

传入 `--appearance-only` 可检查主题、公式大纲、项目名设置与搜索替换布局，并生成渲染图。`--output "输出目录"` 可为 WPF 测试指定独立的截图和配置目录。

传入 `--crop-only` 可编译带页码、图块和大段空白的真实文档，检查自动裁边、连续填充、开关保存和裁切后的 SyncTeX 定位，并生成裁边前后截图；需要工作区中的便携 Tectonic 和已有字体缓存。PDF 控件测试另外覆盖旋转页面、裁切框、空白页、灰背景、栅格预算、缩放锚点和取消分析。

传入 `--completion-only` 可验证 Enter／Tab 确认补全后关闭候选框、引用键的连续补全、占位光标、撤销和 Escape。传入 `--layout-only` 可使用 Tectonic 和本机安装的 MiKTeX 引擎，验证非对称奇偶页边距、装订边、短行及 `newgeometry`；PDF 控件测试另覆盖缺失版心时的回退和越界内容不改变版心宽度。

传入 `--outline-profile "主文件路径" ["已有 PDF 路径"]` 可只读测量标题点击及编辑区重绘耗时，提供 PDF 时还测量 SyncTeX 定位；使用独立测试设置，不触发编译。首次字形排版通常比重复跳转慢，测量中的 SyncTeX 时间不包含自动跟随的防抖等待和后续 PDF 栅格绘制。

传入 `--follow-existing "主文件路径"` 可只读复查已有编译产物：正反向滚动源码第 68～84 行，并分别检查裁边开启／关闭，验证这一跨页回跳案例；还会检查源码滚动到底时自动显示 PDF 最后一页且不移动光标。只输出源码行号与预览滚动位置，不保存或重新编译用户文档。通用的分页辅助记录误匹配另有合成 SyncTeX 回归样本。

传入 `--outline-interactive` 可打开独立的点击诊断窗口。窗口标题显示大纲跳转次数与目标行，便于人工检查连续单击、留白命中和焦点切换；关闭窗口即可结束。

## 项目结构

- `src/TeXeed.Core`：项目发现与保存、索引、格式化、工具链、编译、SyncTeX。
- `src/TeXeed.App`：WPF 窗口、编辑器、PDF 预览与设置。
- `tests`：核心、控件和本机渲染检查。
- `examples`：可直接打开的示例工程。

编译中间文件放在项目的 `.texeed/build`，最后成功的 PDF 和 SyncTeX 保存在 `.texeed/preview`。应用设置与最近项目默认保存在 `%LOCALAPPDATA%\TeXeed\settings.json`；可用 `TEXEED_HOME` 环境变量指定独立配置目录。

打开项目优先恢复上次成功的本地预览。缓存记录匹配源码、图片、文献、实际编译依赖和引擎时直接使用，不启动编译；修改后保留旧预览并在后台更新，继续复用辅助文件与文献结果。旧版本没有缓存记录的 PDF 也先显示，开启实时预览时后台编译一次建立记录。手动编译仍可明确刷新结果。

TeX Live／MiKTeX 编译器从项目目录运行，输入和输出参数使用相对路径与正斜杠，兼容 TeX Live 在中文目录下的编译。Windows 上若同时安装 MiKTeX 和 TeX Live，可在设置中明确选择 XeLaTeX 并填写所需发行版的 `xelatex.exe`、`synctex.exe` 路径；不必更改系统 PATH。

## 当前边界

- 这是 Windows x64 版本；未提供 ARM64 原生构建。
- 文件解析是静态分析，动态 TeX 宏生成的路径不会展开。跨出主文件目录的依赖以及符号链接会被拒绝并提示；请把项目依赖整理到主文件目录中。
- 实时预览仍需让 TeX 引擎处理整份文档；增量复用中间结果并减少重复遍数，耗时取决于工程、引擎和宏包。每次编译最长两分钟，可以手动停止。
- PDF 的反向定位精度取决于编译器产生的 SyncTeX。修改源码后，需更新编译结果再定位，避免误跳行。
- PDF 预览当前以页面渲染和同步定位为重点，不提供 PDF 文字选择、批注或表单编辑。
- 格式化只调整可判断的结构缩进，保留注释和 verbatim 类环境，不替代完整 TeX 宏展开。
