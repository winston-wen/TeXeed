# TeXeed

适用于 Windows x64。

1. 安装 [.NET 10 桌面运行时](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)，选择 **.NET Desktop Runtime → Windows → x64**；已安装可跳过。
2. 将 TeXeed ZIP 解压到固定文件夹，双击 `TeXeed.exe` 启动。
3. 排版 LaTeX 另需安装 [TeX Live](https://www.tug.org/texlive/windows.html) 或 [MiKTeX](https://miktex.org/download)，然后在“排版 → 设置”中检测引擎。
