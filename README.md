# TeXeed

适用于 Windows x64。

1. 安装 Microsoft Edge WebView2 Runtime（Evergreen x64，已安装可跳过），并安装 Git 且确保 git 命令位于 PATH 中，以启用文稿版本记录。
2. 安装 [.NET 10 桌面运行时](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)，选择 **.NET Desktop Runtime → Windows → x64**；已安装可跳过。
3. 将 TeXeed ZIP 解压到固定文件夹，双击 `TeXeed.exe` 启动。
4. 排版 LaTeX 另需安装 [TeX Live](https://www.tug.org/texlive/windows.html) 或 [MiKTeX](https://miktex.org/download)，然后在“排版 → 设置”中检测引擎。
