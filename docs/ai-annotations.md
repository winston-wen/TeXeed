# AI 批注与只读块式回答（0.3.14）

开启左侧「AI 圈点」，在源码或 PDF 单击／拖选后即可在原位写批注，不切换当前标签。未发送的圈点在原位显示编号气泡，同时保留在 AI 消息编辑栏的条目列表中。点击气泡可以继续编辑、收起或删除；两个位置共用同一份批注内容，自动保存到项目的当前会话。编号递增，删除条目不复用编号。

AI 已完成的回答也支持圈点：选中文字后松开，或单击一个段落，在原位填写批注；不开启圈点时，可以右键选择「批注所选内容」。回答正文只读，复制和选择仍可用。批注发送时附带被引用的回答内容、轮次和片段标识，公式引用保留 LaTeX 源文。正在流式生成的回答需等本轮完成后再批注。

气泡仅显示当前会话的待发送／失败重试条目。提交中和已完成的气泡隐藏，编辑栏仍保留条目和状态。源码位置在当前编辑过程中随文本插入移动；重新打开时校验原版本，或用唯一的原文片段重定位。无法确认位置、原文被删除或 PDF 版本变化时隐藏气泡，条目和快照仍保留，避免错误定位。PDF 气泡随滚动、缩放和裁边坐标变换移动。切换会话与重新打开项目会恢复草稿。

## 排版

- 标题、段落、粗体、列表、引用、代码块、表格以原生只读块排版；不执行 HTML，不自动请求远程图片。
- 行内公式：`$x^2$`、`\(x^2\)`；独立公式：`$$...$$`、`\[...\]`，也识别 `equation` 环境。
- 独立公式在当前回答片段内自动编号；`\tag{A}` 指定显示编号，`\label{mapping}` 设置跳转目标。正文中的 `\eqref{mapping}`、`\ref{mapping}` 和 `[公式](#mapping)` 可以跳转，支持先引用后定义。未找到的引用保留标识与问号。
- 行内和行间数学均使用本机 **LaTeX → DVI → SVG**，加载 `amsmath`、`amssymb`，由 `dvisvgm --no-fonts` 将真实 TeX 字形转为 SVG 路径。WPF 直接绘制矢量路径，无位图缩放损失；行内按 TeX 盒子的基线、宽度、高度和深度与文字对齐，行间使用 display style 并保留自然高度。`\mathbb E`、`\operatorname`、分式、求和、矩阵及 `aligned` 使用原生 TeX 排版，整个公式块使用一个编号。
- 需要 TeX Live 或 MiKTeX 中的 `latex`、`dvisvgm` 和 AMS 宏包。首次在后台生成，短暂显示省略号；同一公式共享任务和本地 SVG 缓存（最多 512 项／64 MB），主题、缩放、分栏重排不必重新编译。独立公式可横向滚动，Shift＋滚轮横向查看；普通滚轮滚动对话。展开的计算过程先滚动自身，到边界后继续滚动对话。
- 数学片段使用固定前导、数学命令及环境白名单，不载入项目宏定义，不允许文件读写命令、shell escape、外部 SVG 资源或动态宏编程。编译有并发和超时限制；缺少工具、语法错误或不支持的命令会保留源文，悬停显示原因。代码中的美元号和反斜杠保持原样，复制／批注仍得到原始 LaTeX。
- 管道表格支持表头与单元格内的行内公式。

需要分栏时使用以下块语法。宽度不足 560 DIP 时，各栏按原顺序上下排列，气泡仍对应原内容。

```markdown
:::: columns
::: column
### 拼接
$x\mapsto x\Vert 0^n$ 是单射。
:::
::: column
### 哈希
不同输入可能产生相同输出。
:::
::::
```

## 验证

`dotnet run --project tests/TeXeed.AppTests -c Release -- --ai-math-scroll-only --output artifacts/ai-math-svg-check` 使用本机 TeX 引擎验证三个期望公式、黑板粗体、真实 SVG、行内／行间样式与基线、缓存复用、错误回退、深浅主题及嵌套滚轮行为。需要上述 TeX 工具与 AMS 宏包。

`dotnet run --project tests/TeXeed.AppTests -c Release -- --ai-annotations-only --output artifacts/ai-annotations-check` 检查公式矢量、源码复制、编号引用、分栏重排、深浅主题、原位双向编辑、源码移动、PDF 缩放、回答引用、持久化和会话隔离，并输出截图。

`--ai-only` 继续覆盖现有流式回答、取消重试、选区颜色与源码／PDF 上下文。测试程序在创建窗口之前固定独立的 `TEXEED_HOME`，并验证不会使用正式用户凭据目录；Windows DPAPI 测试需在正常用户环境运行。
