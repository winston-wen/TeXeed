# AI 共同文稿与圈点

## 从问题到文稿

每个会话维护一篇单文件 LaTeX 文稿和附着其上的评论。模型首稿被要求包含文档类、导言区和 document 环境；后续修改仍作用于同一份源文。模型提示词要求不引入其他 TeX 源文件；该约定目前不对任意自定义宏和用户手动输入做完整依赖验证。先在下方编辑栏提问，模型生成初稿；之后可以直接编辑文稿、选中文字添加评论，或在编辑栏中要求模型检查、解释、补充和改写。文稿与关联评论是持续阅读和整理的对象；用户可以自己改写，也可以指示模型改写，自行决定何时整理与停止迭代。模型的实质性修改可附带理由，不需要接受或拒绝修改。

内置提示词要求模型将附言用作批改摘要，把具体修改和意见放在正文或关联评论中；附言原则上不超过用户附言的 3 倍，或不超过 200 字，满足一项即可。此约束由模型遵循，程序不强制截断或验证长度。

编辑栏是发送共同文稿时的总附言。提交后临时显示本次附言与处理状态；处理结束后收起。模型返回的附言写在文稿头部并标明模型名，随文稿保存版本。后续附言更新同一位置；用户修改过或附有评论的内容会保留，新摘要加在其前，用户可自行整理。

起始问题显示在文稿上方。正文中用户文字使用手写风格字体，模型文字使用正文字体；评论和版本标明作者。应用没有设置用户名时显示「用户」，模型作品使用所选模型的显示名称。

本会话文稿与项目的主文件及其包含文件分开保存。圈点的源码、PDF 选区和提问作为研究资料；要求修改项目文件时，模型可以依照当前权限使用项目工具。

## 编辑、评论和版本

在正文中编辑文字，Enter 新建段落。双击公式可编辑其 LaTeX 源码；代码块可编辑。工具栏的「LaTeX 源码」提供源文编辑，适合涉及多个段落或尚未支持可视编辑的命令。选中同一段普通文字后添加评论，也可以回复和编辑现有评论。原位置被删除的评论仍保留，并标明位置已失效。

渲染器识别完整文档外壳、普通段落、常见分节、强调、列表、常用公式环境、verbatim 和 lstlisting 代码，以及部分简单的导言区数学宏；它不是完整的 TeX 编译器。未识别的 LaTeX 命令以原文保留，公式错误显示原文。跨段和公式内部的选区评论暂不支持；源文一次直接替换的选区限制为 128 字符。

文稿及评论随会话保存，另在每会话独立目录和 Git 仓库中记录文稿及资源版本。「版本」中的「打开会话目录」用于放入图片、bib 等文件；相对路径从该目录解析。放入或修改资源后可使用「保存当前版本」创建快照；恢复旧版本时会先保存恢复前的文稿和资源。图片展示支持 PNG、JPEG、GIF、WebP、BMP 和 SVG；单张不超过 20 MB，符号链接不读取。Bib 引用暂显示引用键，尚未按 bib 文件与样式生成参考文献。恢复资源时，单个文件不超过 64 MB，一次恢复的前后资源合计不超过 256 MB；检测到外部并发修改时保留文件和恢复记录，不自动覆盖。重命名当前项目的主 TeX 文件后，现有会话目录暂不会自动迁移，旧目录和 Git 历史仍保留；在完成迁移支持前应避免该操作。模型生成期间文稿发生变化时，旧结果不会覆盖新编辑，未应用的内容可复制；对已经改变的评论也不会直接套用基于旧内容生成的回复。

## 评论与搜索

发送时使用当前会话的完整文稿和评论快照，不将旧聊天轮次作为上下文，也不自动摘要或截断文稿。重试继续使用原请求快照，保留新草稿。模型仍有上下文容量限制；服务端明确报告超限时，可换用容量更大的模型，文稿不会因此改动。

文稿右侧浮球提供标题和公式书签，可拖动至文稿和评论区内的位置；当前不能拖到下方编辑隔间。Ctrl+G 搜索当前文稿。普通搜索按源文匹配；勾选增强搜索后，发送当前文稿和搜索内容给可用的 nano 或 mini 模型，结果仍须能在源文中定位。当前增强搜索单次支持最多 8 万字符，模型或网络不可用时可使用普通搜索。

## 圈点

开启「AI 圈点」后，可在源码或 PDF 中创建条目；确认条目只把它选入待发区，不单独请求 AI，也不清空主编辑栏。主编辑栏发送时将所选圈点和统一问题一起提交；已可靠记录的请求固定快照，重试使用该快照。等待期间新增的条目和草稿保留。

源码锚点随编辑移动；原文删除、定位歧义或 PDF 版本改变时，条目仍保存在列表中。

## 验证

使用 `TeXeed.AppTests --ai-shared-document-only` 验证文稿、评论及 Git 版本，使用 `--ai-mentor-protocol-only` 验证模型结果和锚点，使用 `--ai-mentor-integration-only` 验证请求流程。`tests/ai-document-bridge.test.cjs` 检查本地 HTML 的渲染与消息桥；性能方法及样本见 [排版与性能](ui-layout-and-performance.md)。
