# AI 批注与只读块式回答（0.3.18）

开启左侧「AI 圈点」，在源码或 PDF 单击／拖选后即可在原位写批注，不切换当前标签。未发送的圈点在原位显示编号气泡，同时保留在 AI 编辑区“圈点”按钮打开的条目列表中。点击气泡可以继续编辑、收起或删除；两个位置共用同一份批注内容，自动保存到项目的当前会话。待发条目连续编号；每次发送按本轮从 1 开始编号。原位批注中的 Ctrl+Enter 仅发送该条，不清空主草稿。

AI 已完成的回答也支持圈点：选中文字后松开，或单击一个段落，在原位填写批注；不开启圈点时，可以右键选择「批注所选内容」。回答正文只读，复制和选择仍可用。批注发送时附带被引用的回答内容、轮次和片段标识，公式引用保留 LaTeX 源文。正在流式生成的回答需等本轮完成后再批注。

气泡仅显示当前会话的待发送条目。发送快照可靠落盘后，所选条目立即移出编辑区和气泡层；答复停止或失败也不回填，点击历史批注链接仍可临时查看原文和 PDF 截图。未勾选及等待期间新增的圈点保留；可靠记录失败时不清空草稿。重开项目会核对 ID、问题与来源内容，清理已发旧条目，保留已修改草稿。源码位置在当前编辑过程中随文本插入移动；重新打开时校验原版本，或用唯一的原文片段重定位。无法确认位置、原文被删除或 PDF 版本变化时隐藏气泡，条目和快照仍保留，避免错误定位。PDF 气泡随滚动、缩放和裁边坐标变换移动。切换会话与重新打开项目会恢复草稿。

## 排版

- 标题、段落、粗体、列表、引用、代码块、表格以原生只读块排版；不执行 HTML，不自动请求远程图片。
- 行内公式：`$x^2$`、`\(x^2\)`；独立公式：`$$...$$`、`\[...\]`，也识别 `equation` 环境。
- 独立公式在当前回答片段内自动编号；`\tag{A}` 指定显示编号，`\label{mapping}` 设置跳转目标。正文中的 `\eqref{mapping}`、`\ref{mapping}` 和 `[公式](#mapping)` 可以跳转，支持先引用后定义。未找到的引用保留标识与问号。
- 行内和行间数学均使用本机 **LaTeX → DVI → SVG**；含中文片段自动使用 **XeLaTeX → XDV → SVG**（xeCJK、系统 Microsoft YaHei 字体）；黑板体小写字母／数字使用 XeLaTeX、unicode-math 与 Latin Modern Math，避免 AMS 字库缺字，加载 `amsmath`、`amssymb`，由 `dvisvgm --no-fonts` 将真实 TeX 字形转为 SVG 路径。WPF 直接绘制矢量路径，无位图缩放损失；行内按 TeX 盒子的基线、宽度、高度和深度与文字对齐，行间使用 display style 并保留自然高度。`\mathbb E`、`\operatorname`、分式、求和、矩阵及 `aligned` 使用原生 TeX 排版，整个公式块使用一个编号。
- 需要 TeX Live 或 MiKTeX 中的 `latex`、`dvisvgm` 和 AMS 宏包。首次在后台生成，短暂显示省略号；同一公式共享任务和本地 SVG 缓存（最多 512 项／64 MB），继续复用 0.3.14 已有缓存。新公式按约 15 ms 收集窗口合并，每批最多 24 个公式，在同一个临时 TeX 文档内逐页排版，一次启动 LaTeX 和 dvisvgm，按页输出独立 SVG。已有磁盘缓存绕过编译队列，重复字形共享矢量；主题、缩放、分栏重排不必重新编译。单个语法错误触发分批定位，避免拖垮同批其他公式；失败结果暂存 30 秒，防止流式刷新反复启动失败任务。
- 独立公式可横向滚动，Shift＋滚轮横向查看；普通滚轮滚动对话。展开的计算过程先滚动自身，到边界后继续滚动对话。
- 数学片段使用固定前导、数学命令及环境白名单，不载入项目宏定义，不允许文件读写命令、shell escape、外部 SVG 资源或动态宏编程。编译有并发和超时限制；缺少工具、语法错误或不支持的命令会保留源文，悬停显示原因。代码中的美元号和反斜杠保持原样，批注仍得到原始 LaTeX。
- 管道表格支持表头与单元格内的行内公式。

需要分栏时使用以下块语法。宽度不足 560 DIP 时，各栏按原顺序上下排列，气泡仍对应原内容。

```markdown
:::: columns
::: column
### 拼接
$x\mapsto x\Vert 0^n$ 是单射。
:::
::: column
### 哈希
不同输入可能产生相同输出。
:::
::::
```

## 复制与自动校对（0.3.16）

选区 Ctrl+C、右键「复制」及「复制这段回答」均输出 Unicode 文本，避免目标应用优先粘贴 RTF／XAML 中的公式图像。行内公式输出 `文字 $x$ 文字`，美元号外两侧各一个 ASCII 空格，已有多余空格会归一；只选公式时同样保留两侧空格。行间精确输出 `$$\n公式源码$$\n`，使用 LF 换行，保留原文中的显式 tag／label，不添加界面自动生成的编号。代码中的数学示例原样复制，公式还在加载或编译失败时也能复制源文。剪贴板空格与批注定位坐标独立，旧批注不会因格式变化移位。

新回答在本轮结束前逐一检查已识别的不同公式，使用与界面相同的真实 TeX／SVG 引擎和缓存；代码块及行内代码不触发数学检查。检查包含 TeX 语法、未闭合的数学定界符以及缺失字形。失败时将原稿和诊断收进可展开记录，由 AI 修复排版语法，返回完整修正版，再次编译。此阶段禁用项目工具，要求保持数学含义与正文，并拒绝靠删去全部／部分公式跳过校对的回答。仅检查排版可编译性，不声称证明数学推理正确。

通过后才记录回答完成时间与成功状态。缺少引擎／宏包时直接报告环境问题；最多自动修正 5 次，仍未通过则明确标记未完成，保留原稿与错误供继续处理，避免无限请求。停止按钮也可中断校对。已有包含中文的回答会在重新显示时用新的中文渲染路径加载，不改写原始回答。

## 验证

`dotnet run --project tests/TeXeed.AppTests -c Release -- --ai-math-scroll-only --output artifacts/ai-math-svg-check` 使用本机 TeX 引擎验证三个期望公式、黑板粗体、真实 SVG、行内／行间样式与基线、缓存复用、错误回退、深浅主题及嵌套滚轮行为。需要上述 TeX 工具与 AMS 宏包。

`dotnet run --project tests/TeXeed.AppTests -c Release -- --ai-annotations-only --output artifacts/ai-annotations-check` 检查公式矢量、源码复制、编号引用、分栏重排、深浅主题、原位双向编辑、源码移动、PDF 缩放、回答引用、持久化和会话隔离，并输出截图。

`--ai-only` 继续覆盖现有流式回答、取消重试、选区颜色与源码／PDF 上下文。测试程序在创建窗口之前固定独立的 `TEXEED_HOME`，并验证不会使用正式用户凭据目录；Windows DPAPI 测试需在正常用户环境运行。

## 公式加载性能（0.3.15）

本机 TeX Live 2026，24 个不同的 AMS 求和／分式公式，同一测试夹具的首次加载耗时：0.3.14 为 11.96 秒，0.3.15 为 1.44 秒，约快 8.3 倍。重开进程读取这组 SVG 磁盘缓存约 0.10 秒，同进程内存复用不到 1 ms。计时从提交渲染请求到全部矢量就绪，不含应用启动、构建和截图时间；实际耗时随公式复杂度和机器变化。

`--ai-math-perf-only --output artifacts/math-perf` 测量 24 个公式首次／磁盘／内存加载，记录 `math-performance.jsonl` 与 UI 响应；第一次使用新输出目录测首次加载，再用同一目录重开测试进程测磁盘缓存。

`--ai-math-batch-only --output artifacts/math-batch` 验证错误公式隔离、失败任务复用、行内与行间样式混排、批量和单独排版几何一致，以及编译槽占满时缓存仍可立即加载。

`--ai-math-copy-only` 验证精确空格与换行、代码保护、原始标签、纯文本复制命令及两处含中文的截图公式。

`--ai-math-proofread-only` 使用隔离凭据和内存假服务器验证多次校对、诊断传递、失败稿保留、工具隔离、遗漏公式防护、取消、环境失败及真实 AI 面板完成状态；不向真实模型发送请求。
