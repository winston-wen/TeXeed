# AI 共同文稿与评论

## 会话文稿

每个 AI 会话维护一份单文件 LaTeX 文稿，与用户项目的主文件分开。首次提问后，模型生成初稿；之后可以直接在该会话的源码标签编辑，或通过附言要求 AI 检查、补充和修改。文稿可以引用会话目录中的图片、bib 等非 TeX 资源，不应使用 `\input` 或 `\include` 拆分其他 TeX 文件。

编译前会扫描可静态解析的文件依赖，发现会话文稿引用其他 TeX 文件时停止编译；动态宏生成的路径和会话目录外的绝对路径未必能被扫描发现。编译器按现有 TeX 环境运行，构建目录隔离不等于沙箱，不能将静态扫描视为对所有 TeX 输入的强制限制。

会话源码编辑器使用已有编辑器及其字体、字号和换行设置。源码更新时会检查编辑器读取的修订号；若其他修改先一步更新文稿，本地输入保留在编辑器中，并提供复制后重新载入的冲突处理。处理前不能关闭相关会话或切换项目。

左侧附言是提交整篇共同文稿时的问题或指示。发送使用当时的文稿和评论快照；重试使用原请求快照，保留新的附言与评论草稿。不会为适应模型窗口自动截断或摘要共同文稿，服务端报告上下文超限时保留原文。模型提示词要求附言作为批改摘要写在文稿头部并标明模型名：长度原则上不超过用户附言的 3 倍，或不超过 200 字，满足任一条件即可；程序不强制截断或验证长度。模型生成期间如文稿发生变化，旧结果不会直接覆盖新编辑；已改变的评论也不会直接套用旧快照生成的回复。

## 评论

在会话源码中选择文字，点击「评论选区」，在左侧输入并添加评论。评论记录所选源码、位置和源码修订号；用户显示用户名或「用户」，AI 评论显示模型名。评论与回复可在左侧展开后修改；局部保存不会发送 AI 请求。新评论、回复和尚未保存的修改随会话保存。若保存前同一条评论被其他修改更新，侧栏保留输入并显示当前内容，需检查后再以当前内容为基础保存。

源码发生变动时，锚点按编辑移动；所选文字被删除后标记为位置失效。文稿和评论不需要逐条接受或拒绝。

## PDF 预览

在会话源码或 PDF 标签点击「编译会话文稿」，会话 PDF 使用现有预览器及预览设置。源码变化后，已有预览标为过期；编译失败保留上一份成功 PDF，源码和评论不因失败而删除。项目源码有未编译修改时，项目预览也显示过期提示。

如果会话编译失败，展开「编译日志」查看输出，可选择文字复制，也可点击「复制日志」复制全部输出。回到源码标签修正后，再点击「编译会话文稿」；成功后显示新 PDF。

会话 PDF 的「只读评论」显示当前评论及回复。点击评论时使用源码与 SyncTeX 映射尝试定位：成功时标明【近似位置】，不能映射或锚点失效时标明无法定位，预览过期时要求重新编译。预览不提供正文或评论编辑。项目源码可通过右键「查看项目评论」或选择文字后右键「为选区添加项目评论」，在独立的左栏查看、编辑和回复；项目评论与 AI 会话评论分开保存。项目 PDF 的「项目只读评论」展示项目文件的评论与回复，点击后仅在该 PDF 的编译输入仍与当前源码一致时尝试 SyncTeX 近似定位。

## 版本与资源

左侧「版本」打开会话版本记录，可以查看历史文稿、保存当前版本、打开会话目录或恢复历史版本。会话目录独立保存文稿、评论及资源，Git 版本记录与该会话关联。恢复前先保存当前版本；恢复期间若文稿或资源发生外部修改，不自动覆盖新内容。

图片与其他资源的相对路径以会话目录为基准。放入或修改资源后，可在版本窗口保存当前版本。恢复资源时单个文件不超过 64 MB，一次恢复的前后资源合计不超过 256 MB；若恢复中断，版本窗口提供恢复入口。重命名项目主 TeX 文件时，现有会话目录暂不会自动迁移，旧目录及 Git 历史仍保留。为避免项目评论脱离其源码，存在项目评论或草稿时暂不能重命名对应源码；项目含评论或草稿时暂不能重命名主文件。

## 验证

`TeXeed.AppTests --ai-shared-document-only` 检查文稿、评论与 Git 版本，`--ai-mentor-protocol-only` 检查模型结果和锚点，`--ai-mentor-integration-only` 检查请求流程；会话源码、编译与评论侧栏另有专项；`--project-comment-store-only` 和 `--project-comments-ui-only` 分别检查项目评论存储和原生交互。测试参数见 [开发说明](development.md)，性能方法及样本见 [排版与性能](ui-layout-and-performance.md)。
