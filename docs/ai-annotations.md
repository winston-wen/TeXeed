# AI 批注与排版

## 批注生命周期

开启“AI 圈点”后，在源码或 PDF 中单击、拖选即可创建批注。在原位气泡和 AI 编辑区的圈点列表中编辑的是同一份内容，修改随当前会话保存。

批注框及圈点列表的 Ctrl+Enter／右上角箭头将条目选入待发区并收起。只有 AI 主编辑框的发送操作才请求 AI、固定本轮快照并移除已发送条目。主草稿和未勾选条目在确认批注时保留，确认后的批注仍可继续修改。

弹框右上角提供删除和确认。行号仅统计实际换行，自动折行与内部滚动保持对齐。松开鼠标、失焦和 Esc 保持弹框；原文滚动、缩放、移栏、隐藏或区域变化时保存并收起。重新打开继续编辑原条目。

已完成的 AI 回答支持选区或段落批注，引用保留原回答内容、轮次、片段及 LaTeX 源文。发送快照落盘后，选中条目移出待发列表；停止或失败的请求仍保留历史快照。等待期间新增的条目留在草稿中。

源码锚点随编辑移动，重新打开时通过版本或唯一原文定位。原文删除、定位歧义或 PDF 版本改变时隐藏气泡，条目仍保存在列表中。PDF 锚点使用与阅读视图一致的裁边、缩放与滚动映射。

## 回答排版

支持标题、列表、引用、表格、代码和链接。代码采用等宽字体；原始 HTML 按文本显示。宽表格在自身区域横向滚动，表内文字仍可选择、复制和圈点。

图片支持项目相对路径、本地文件和 HTTP(S) 地址，按需加载 Windows 可解码的 PNG、JPEG 等位图；无法解码的格式显示替代文字。点击图片或 PDF 快照可打开预览，放大、缩小、适应窗口或查看原尺寸；Esc 关闭并返回原图。浏览器原型另可预览 SVG。

行内公式使用 `$...$` 或 `\(...\)`；独立公式使用 `$$...$$`、`\[...\]` 或 `equation`。独立公式自动编号，`\tag` 指定编号，`\label` 配合 `\ref`、`\eqref` 或片段链接跳转。宽公式可横向滚动。

数学排版使用 LaTeX → DVI → SVG；中文和部分 Unicode 数学使用 XeLaTeX → XDV → SVG。需要 LaTeX、XeLaTeX、dvisvgm、AMS、xeCJK 与 unicode-math 等相应宏包。公式采用固定导言区和命令白名单，字形转换为矢量路径。缺少依赖或语法错误时显示源文及错误原因。

新公式合并为每批最多 24 个，复用任务及 SVG 缓存。批内错误通过拆分定位，缓存命中直接加载。主题、缩放和分栏复用矢量。分栏语法如下，窄视区按顺序纵向排列：

```markdown
:::: columns
::: column
第一栏：$a+b$。
:::
::: column
第二栏：$a-b$。
:::
::::
```

## 复制与校对

复制输出 Unicode 文本和公式源文。行内公式两侧各保留一个空格；行间格式为 `$$\n公式源码$$\n`，保留显式 tag 和 label。代码内容按原文复制，自动显示的编号不加入复制结果。

新回答结束前检查公式的排版语法、定界符和字形。失败时保存原稿与诊断，由 AI 修正后重新编译，最多五次；校对期间禁用项目工具。缺少工具或宏包时报告环境错误。停止按钮可中断校对，通过后记录完成状态与时间。

## 验证

`TeXeed.AppTests` 提供以下专项参数，使用 `--output` 指定输出目录：

| 参数 | 验证范围 |
| --- | --- |
| `--ai-pins-only` | 弹框焦点、共享编辑、行号和视区变化 |
| `--ai-reading-only` | 确认阶段零请求、草稿保留和主发送快照 |
| `--ai-annotations-only` | 源码、PDF、回答锚点及会话恢复 |
| `--ai-math-scroll-only` | SVG、基线、主题及滚轮 |
| `--ai-math-batch-only` | 批量排版、缓存和错误隔离 |
| `--ai-math-copy-only` | 精确文本复制、公式及代码 |
| `--ai-math-proofread-only` | 校对、诊断、取消及环境错误 |
| `--ai-math-perf-only` | 首次编译、磁盘缓存和内存复用耗时 |
| `--ai-reading-media-only` | 标题编号、宽表复制与批注、图片预览及缩放 |
| `--ai-compact-only` | 三行编辑栏、圆角对齐、行号滚动和过程详情 |

原型交互回归位于 `prototypes/ai-chat-v02`，UI 简评见 [排版与性能](ui-layout-and-performance.md)。

## 会话排版与编辑

原生程序与浏览器原型的过程详情及行号采用 13px 等宽细字，与步骤概述同字号。详情只有一行且与概述完全相同时，直接显示概述；其余详情按需展开。轮次以浅金色 `[1]` 悬挂在用户问题左侧。时间在“发送”“答复”“程序中止”或“用户中止”标签之前。

回答标题沿用正文排版，行内前置浅金色 `[轮次:h级别]`；例如 `[3:h3]` 表示第三轮的 Markdown 三级标题。标题仍可点击折叠下属内容，标记不写入复制文本或圈点引文。

主编辑区默认预留三行并显示三个行号，空草稿不写入占位换行。底栏不设上边线，仍可拖动上缘调整高度。

宽表格在自身区域横向滚动，也可聚焦后用左右方向键操作。Markdown 图片及 PDF 快照支持点击、Enter 或空格打开预览；预览提供放大、缩小、适应窗口与原尺寸，Esc 关闭后焦点返回原图。

视觉预览中的“AI → AI 历史 → 试飞档案 · 图表”提供合成宽表与图片示例；已有会话和草稿保持原样。
