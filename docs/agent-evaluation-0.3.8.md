# 0.3.8 交互与上下文验证

日期：2026-10-14。基于 0.3.7；不修改用户真实 TeX 项目。

## 本版变化

- Shell 行按意图显示成功/失败，点击展开命令与已捕获输出，详情随对话保存。
- 权限框先给白话说明，可展开只读编辑器；拒绝、允许一次、允许类似、其他意见。其他意见支持多行、Ctrl+Enter 和按钮提交，不会执行原命令。
- 允许类似限同会话、同目录：简单 git log/status 的明确只读参数共享授权；复杂脚本只记住原命令。不会用任意前缀放行另一条命令。
- 新增 ask_user 工具，提供方案及影响、自定义意见和停止取消；只读模式也可询问。
- 历史与工具循环自动摘要压缩，保存覆盖轮次及内容指纹；历史改变后失效，失败不丢原文。当前问题与附图保留，工具调用/结果成对整理，不重放孤立调用。摘要请求与后续请求绑定同一连接身份。
- 时间戳移出用户消息框；缓存 PDF 警示；侧栏 AI 圈点图标；删除预览右键菜单及编辑器圈点菜单项。
