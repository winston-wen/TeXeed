# PDF 打印与预览

文件菜单统一为“打印与预览…”（Ctrl+P；Ctrl+Shift+P 保留为同一入口）。窗口使用 Windows 原生纯文字标题栏“打印：文件名”，只有关闭按钮；所有设置、输出面预览与打印提交在同一窗口完成。

## 页码与版式

- 全部、打开窗口时的阅读当前页、指定范围、当前视图区域。指定范围支持 `1, 3, 5-8`、逆向范围和中文分隔符；保留输入顺序并去重。
- 常驻虚线框第一行按顺序流式排列“不分奇偶”“奇数页”“偶数页”“逆序打印”，放不下自动换行；下一行单独显示实际页码。三项及以上连续的奇数或偶数页压缩为横杠范围，筛选时添加“（仅奇数）”或“（仅偶数）”前缀。
- 当前视图捕获阅读区当前页可见部分在原始 PDF 中的矩形。阅读区压缩过的空白会还原为原始 PDF 区域；不会改变源 PDF。阅读当前页与打印预览输出面彼此独立。
- 单页支持适合可打印区域、实际大小、仅缩小大页及 1–1000% 自定义倍率。点击倍率输入框后，滚轮每格调整 1%，Shift+滚轮调整 0.1%；旁边的刷新按钮及 F5 保留当前设置。
- 每张多页支持 2、4、6、9、16 页，行序或列序和页边框。
- 小册子补足四页，按左／右装订顺序拼版，可选正反面、仅正面或仅背面。两面输出需要选择双面方式。
- 海报按物理倍率分片，支持重叠边与拼接辅助线，限制为 10,000 个输出面。

## 纸张、设备与提交

页面设置包含 A4、A3、Letter、自定义尺寸、自动／纵向／横向及四个物理页边距。实际边距不会小于驱动报告的硬件边界。单页模式可按 PDF 页面尺寸选择纸张；混合横竖页面的自动方向可逐面变化。驱动若替换了不支持的纸张，预览使用其验证后的纸张与可打印区域。

打印机发现与能力查询在独立 STA 线程进行，按打印机、纸张和方向缓存；驱动不可用时仍可按安全边距预览，禁用提交。打印机属性通过 `DocumentProperties` 打开设备驱动自己的原生窗口，使用 `PrintTicketConverter` 往返设备配置，取消不改变本次设置。设备专有的省墨、纸盒、质量选项由驱动控制，不修改系统默认打印设置。

输出支持彩色、灰度、黑白及文档与批注／仅文档／仅批注。高级设置提供 150、300、600、1200 dpi；打印分辨率与屏幕查看倍率独立。黑白是栅格转换，设备是否使用单一黑墨仍由驱动决定。

驱动支持时可选自动长边／短边双面，也可手动双面。手动方式先提交正面，等待用户放回纸张，再提交背面；可调整背面逆序与 180° 旋转。不同设备的进纸与堆叠方式应相应选择。奇数面数自动补空白，逐份／不逐份复制均以整张纸为单位，避免正反面跨份。最多 999 份、100,000 个输出面；手动双面取消后不会再提交背面。

## 预览与实现

右侧始终显示可打印虚线边界。双击纸张进入锁定父窗口的独立预览，支持上一面、下一面、指定面、放大、缩小、自动倍率；子窗口关闭前等待渲染结束。

`PdfPrintOptions` 保存任务设置，`PdfPrintPages` 处理有序页码，`PdfPrintPlan` 生成每面纸张与页面放置，`PdfPrintDrawing` 为屏幕和打印生成同一排版结果。`PdfPrintPaginator` 按需提供输出面；`PdfPrintJob` 通过异步 XPS 管线提交，并提供逐面的纸张票据。打印按钮直接提交当前配置，不再弹出第二套系统打印对话框。提交完成仅表示已交给 Windows 队列，不表示设备已经出纸；可取消尚未提交完成的部分。

打印打开独立 PDF 快照；重新编译不会改变进行中的任务。始终使用原始白纸配色。仅批注输出临时隐藏原页内容对象，并在释放页面前恢复。打印采用 PDFium 图像渲染，不保留 PDF 矢量文本；每面源图像合计限制为 32 MP，单边最多 10,000 像素，大纸张会在预算内降低分辨率。预览使用较低分辨率；不会缓存全书图像。

## 验证

`TeXeed.AppTests.exe --print-only --output artifacts/ui-print` 检查有序页码、奇偶与逆序、流式换行、混合纸张、原始配色、批注分离、裁切、缩放、N-up、小册子、海报、双面份数、异步 XPS 输出／取消、原生标题栏、深浅主题、模态子窗口与关闭中渲染，并生成截图，不向实体打印机发送任务。`--print-review` 打开三页彩色样例供手工检查。
