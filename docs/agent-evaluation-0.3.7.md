# 0.3.7 权限、Shell 与对话验收

本版修复的根因是：0.3.6 只有专用项目工具，没有 Shell，且工作规则明确禁止任意命令。仅添加“主动找 Git 历史”的提示词不能补出执行能力。0.3.7 新增真实 PowerShell、宿主权限检查与会话权限选择，同时撤去提示词和目录工具返回中的绝对禁令。

默认“完全访问”使用 Windows 当前用户的实际文件和网络权限；“执行前询问”每条命令展示确认；“只读”不向模型提供写入与命令工具，执行层也拒绝越权调用。没有冒充 Codex 或 Claude Code 的内部提示词，也不宣称复刻了它们的全部沙箱与审批实现。设计参考公开的 [Codex 权限说明](https://learn.chatgpt.com/docs/security)、[Claude Code 权限说明](https://code.claude.com/docs/en/permissions) 和 [OpenAI 工具调用文档](https://developers.openai.com/api/docs/guides/function-calling)。

## 真实模型调查

在用户授权的本地 `svarog_notes` 仓库历史的独立副本上测试，保留 DKLS 项目及 Git 提交历史。任务明确只调查，不安装、不运行安装脚本、不改正文；完整权限仍可使用只读 Shell 查询。原仓库未被改动。

两次历史调查的源文件清单/哈希保持一致，无未保存源码，不调用安装或编译。检查命令记录确认调用过 `git log` 和 `git show`，而非只采信模型自述。DeepSeek 将 POSIX 环境概括为 Linux/macOS；macOS 的具体依赖可用性并未实测，不能把这句话视为原样兼容 macOS 的证明。本次验收针对 Windows 和历史查找，不是全系统安装兼容性测试。

本轮共使用 Sol 6 次、DeepSeek 6 次；沿用此前总账后累计 Sol **40/200**、DeepSeek **65/500**。不按请求数推测费用。

上下文百分比反映最近一次实际请求的输入加输出 token，而非各轮累计消费。没有上下文窗口或没有服务端用量时不编造数值。旧记录没有准确的发送时间，只能保留旧时间含义。Shell 是独立非交互进程，不自动取得管理员权限；用户选中的完整访问不是文件系统沙箱。安装某个真实字体或软件不属于本次发行验收的必要动作，本轮没有替用户安装系统依赖。
