# AI 工作区

## 连接与会话

从 AI 菜单（Alt+A）新建对话、打开设置或管理历史。每个会话独占可关闭、跨栏拖动的标签，独立保存问题、草稿、圈点、权限和视口滚动位置。关闭标签会停止并保存该会话；切换标签时其他会话继续输出。

本版使用轮次对话，已完成的 AI 回答不可直接修改，可对回答添加批注。旧共同文稿版本保存的文稿、评论草稿和请求快照会在会话保存时保留，但本版界面不能显示或编辑共同文稿；会话目录中的资源和版本历史仍保留。

对话阅读区深浅主题的正文均为 18 DIP，中文使用冬青黑体简体中文 W3，英文和数字使用 IBM Plex Sans Regular 并启用点心零。回答标题、标题编号和轮次号使用常规字重。TeX 公式以正文的 18 DIP 为基础字号，行间公式按展示比例放大。普通文本中的数字使用正文字体，显式数学定界符内的数字仍按 TeX 排版。行内公式与同一行的文字共用基线，撇号、下标和分数按 TeX 原有位置绘制。追问气泡按可见中轴对齐相邻文字。IBM Plex Sans Regular 随程序提供。冬青黑体由用户自行提供，放在当前用户的 TeXeed 字体目录中，缺失时使用后备字体。编辑区及代码使用各自的字体。

可以要求 AI 出可直接填写的练习；新回答能在正文或表格中安排单行、行间多行、单选、多选及文件控件。独占一行的单行框铺满宽度；多行框默认三行，显示行号，最多增高至八个显示行。自动折行也计入八行，超出时在框内纵向滚动。文件控件添加的文件或文件夹进入原有附件列表，记录来自哪个回答控件及提供材料的用途；文件上传与文件夹引用沿用附件原有处理方式。需要很长的材料时，可以附上文件。填写内容与回答分开保存，切换或重开会话后可继续填写。发送下一条消息时，填写结果随消息提交给 AI，此后相应控件锁定；主编辑框为空时也可只提交已填写的结果。点击已锁定的控件，可在附近选择解锁该回答的题目，继续填写；之前的提交和判题记录保留，再次发送后题目重新锁定。若该回答的公式仍在排版，解锁会等排版完成，提示可以取消；等待时可继续滚动或编辑草稿，发送新消息或离开会话会取消等待。发送保存失败会保留内容并恢复编辑。生成过程中控件标记可能暂时以原文显示，回答完成后才转换为控件；旧回答不会自动插入控件。

点击或填写回答中的输入框时，阅读区保持当前内容位置；框内光标及表格横向滚动仍按需要调整，方便继续填写。

用户要求判题，或 AI 高度判断某份表单需要判对错时，AI 可以在回复后将判断显示在原控件旁，并重新开放该表单供修改、再次提交。修改字段后，该字段针对旧答案的标记不再显示；历史提交和判断保留。普通答复不会自动解锁，AI 的判定仍需结合具体理由核对。

在 AI 设置中通过系统浏览器登录 ChatGPT，可添加和切换账号或工作区。设置页提供新会话的默认模型和推理强度；在输入栏选择只影响当前会话。追问型分支初始继承来源会话的选择，此后分别保存；已选模型暂不可用时可刷新或改选。支持的选项来自账号模型目录。API Key 使用独立的 API 额度，需要手动启用。

主编辑框中 Enter 与 Shift+Enter 换行，Ctrl+Enter 或发送按钮提交当前问题及勾选批注。发送后可继续写下一条草稿。停止会取消当前请求和本轮编译；已完成的文件修改保留。进展、工具操作和最终回答按时间排列，点击操作文字展开详情。双击问答时间折叠本轮，Ctrl+F 查找消息。

点击发送后，问题、时间和等待状态立即显示；长会话将实时消息带入视口，问题可靠落盘后再清空已发送草稿。状态栏依次显示“等待 AI 响应”“正在生成回复”或“正在处理项目”；网络或服务异常时显示重试倒计时。生成中的编号、正文行框及过程间距与完成后保持一致；状态灯按字形中线对齐，直径与状态字号相同。系统动画开启时灯光呼吸，关闭时每半秒在空心和实心之间切换。临时状态不会写入过程记录，旧会话中的“已连接 AI”等连接提示在显示时隐藏，原始存档保留。

运行中可用发送按钮上方的图标引导当前轮次或将消息排队。引导在当前请求或工具的安全交接处加入；运行中的工具不会被中途重启。排队消息与所选引用和附件分别保存快照，当前轮成功后按顺序发送；消息进入会话后从待处理列表移除，并在正文显示处理状态。停止或中断后剩余队列暂停，已进入会话的消息由正文中的轮次处理；交接结果不明的消息需用户检查后决定是否重试。编辑框中后来输入的草稿不会被队列发送清除。关闭或重新打开会话后，未处理消息留在待处理列表，由用户决定是否继续。底层连接使用 HTTP 流，请求交接并非服务端原生实时引导。

网络连接中断、TLS 连接失败、请求超时和服务过载会持续重试。等待按 1、2、4、8、16、30 秒递增，之后保持 30 秒，停止按钮随时取消等待。流读取连续两分钟没有收到新行时重新连接。已执行的工具结果保留在当前工作循环中，重连只重新请求尚未完成的响应。

只有最后一轮中止时，时间右侧显示“↻ 重试”；用户中止、程序中止和旧的过载失败记录均适用。重试建立新一轮，使用原问题和批注快照，并携带已完成操作记录；下一条草稿及未发批注保留。登录、权限、参数等永久失败保留中止状态，排除原因后可手动重试。

历史管理使用分页工作区，支持标题、问题和回答搜索、多选删除、改名及页码跳转。已打开会话需先关闭再删除。会话标签双击打开改名窗口。圈点和批注的操作见 [AI 批注与排版](ai-annotations.md)。

## 书签与跳转

AI 对话中的书签浮球可左键按住拖动，范围限定在当前对话窗口。点击浮球或在对话内按 Ctrl+G 打开书签菜单；输入用户添加的书签名称筛选，上下键选择，Tab 补全，Enter 跳转。标题和公式不会自动生成书签。跳转会展开目标所在的折叠轮次和章节。

可选中文字添加书签；右键行间公式或图片时先选中该对象，再使用添加书签命令。表格内没有文字选区时，右键选择整张表格；已有选区时保留选区。书签记录来源与文字上下文，内容变化或重复内容无法可靠区分时不会猜测跳转位置。

选中问题或回答中的文字，右键选择「为所选内容添加标签」并填写名称，可在菜单的用户标签区按行文顺序或字典序查找、跳转及删除。标签、排序方式和浮球位置随会话保存。正在生成的回答会在本轮结束后排版，期间为避免锚点错位，添加标签不可用；普通实时提问在恢复记录保存后可以添加，带圈点的实时提问需等本轮结束。已有会话内容不会因生成提示词变更而改写。

## 项目工具与权限

AI 可以列出目录、读取和检索源码、替换或创建文件、保存及编译。开始时提供当前入口、引擎和目录资料；后续按需读取未引用的模板、样式与构建说明。

替换前读取文件并校验指纹和唯一匹配，保留读取之后发生的新编辑。首次替换前建立备份，编辑进入撤销栈。专用源码工具限定项目内路径并拒绝符号链接；`compile_project` 可使用当前入口或项目内已有 `.tex` 入口。

| 会话权限 | 行为 |
| --- | --- |
| 完全访问 | 使用当前 Windows 用户权限执行 PowerShell、文件操作和网络请求 |
| 执行前询问 | 源码编辑、保存和编译自动执行；Shell 等待批准或匹配会话已有授权 |
| 只读 | 提供读取工具，拒绝修改和命令执行 |

Shell 默认在项目根目录启动独立非交互进程，可访问当前 Windows 用户权限允许的路径。

## 内置提示词

[AGENTS.md](../AGENTS.md) 约束 TeXeed 仓库的开发协作。原生程序在 [AiResponses.cs](../src/TeXeed.App/AI/AiResponses.cs) 组装每次 Responses 请求的 `instructions`；项目目录中的 `AGENTS.md` 和其他说明可以按需读取，其内容属于项目资料。

| 请求场景 | 发给模型的指令 |
| --- | --- |
| 普通会话 | [AiAgentPrompt.cs](../src/TeXeed.App/AI/AiAgentPrompt.cs) 规定如何理解项目、使用工具、精确编辑和验证结果。[AiPermissions.cs](../src/TeXeed.App/AI/AiPermissions.cs) 附加本会话权限说明。有工作区时使用这两部分；无工作区工具接入时使用简短的只读助手指令。两条路径都追加 Markdown、公式、标题和表单控件规则。 |
| 重试和选区追问 | 重试追加续接已完成工作要求，选区追问追加按当前疑问回答的要求。两种条件同时成立时均追加。 |
| 生成判题 | 普通答复请求也携带 [AiFormGrading.cs](../src/TeXeed.App/AI/AiFormGrading.cs) 的判题条件和 `texeed-grade` 格式。只在符合条件时由模型输出结构化判题，宿主根据实际提交校验并应用。公式修正请求不附加判题规则。 |
| 自动修正公式 | 沿用普通回答的排版要求，额外要求根据编译诊断只修正数学排版并返回完整正文；此请求的工具列表为空。 |
| 历史与工作上下文压缩 | 单独使用 [AiResponses.Context.cs](../src/TeXeed.App/AI/AiResponses.Context.cs) 的摘要指令，只返回精确的工作状态摘要，工具列表为空。 |

新回答的排版提示词引导模型在标题、正文和表格里直接书写独立数值，例如“取 512 或 64”。算式、上下标、原文引用及用户指定的数学排版保留相应写法。已有回答仍按其保存的 Markdown 渲染。需要分节的新回答从一级标题开始，并逐级展开，省去包裹全文的标题及手写标题序号。简短回答可直接写正文。层级编号由显示层添加，已有内容依原文展示。原生程序在本地从首问截取初始会话名。原型答复使用本地回放，标题和回答指令存入模拟请求记录。[原生标题生成](../src/TeXeed.App/AI/AiModels.cs) · [原型提示词](../prototypes/ai-chat-v02/prompts.json)

当前问题和引文、附件、项目目录、历史摘要在请求 `input` 中提供。用户的请求决定任务；文件内容、引文、编译日志和工具结果供分析。宿主在编辑后未尝试编译、只收到阶段说明或公式排版失败时，会另发相应的运行提示。权限同时用于筛选工具和校验调用，由宿主执行。

## 上下文与保存

请求携带当前会话历史，源码工具读取包含未保存修改的编辑内容。发送批注时固定本轮快照；源码记录相对路径、行号、文本及指纹，PDF 记录原色截图、页码、坐标及指纹。

AI 可按任务读取项目中未被当前主文件引用的源码和模板，创建独立的 `.tex` 文稿，并指定该入口编译；新文稿不必自动加入原主文件。模型对文稿内容关系的判断依赖实际读取的资料和本次指令，不是自动建立的完整语义索引。项目文件可以按权限由用户和 AI 共同编辑；已完成的对话回答仍为只读。

长会话按模型窗口预算生成摘要，保留近期问答和当前问题；界面保留完整记录。上传的文本文件直接携带正文，可能使首轮超窗；引用的目录只先提供部分目录清单，小型文本文件引用会在估算预算允许时携带正文，其他内容可按需读取。工作上下文压缩只摘要此前对话与工具结果，本轮问题和附件保留，不为仅由本轮附件造成的超额重复摘要。估算仅为粗略文本预算，并非精确 tokenizer；图片及 PDF 等二进制附件不把 base64 计作正文，实际处理所占窗口以服务端为准。本轮估算超过已知模型窗口时显示提示并仍尝试发送，明显超窗时不进行无法解决问题的预先历史摘要；服务端拒绝后保留记录，可减少附件或分批处理。上下文百分比采用最近一次请求的服务端用量，后续新增内容按预算估算。摘要随会话保存，相关历史变化时失效。压缩使用当前模型额度，失败时保留原文并停止本次请求。

配置默认位于 `%LOCALAPPDATA%\TeXeed`，设置 `TEXEED_HOME` 后使用指定目录：

| 子目录 / 文件 | 内容 |
| --- | --- |
| `settings.json` | 应用设置及最近项目 |
| `ai/projects` | 按项目主文件路径隔离的会话 |
| `ai/attachments` | 新上传附件的内容快照，多个会话和分叉可能共用 |
| `ai/backups` | AI 替换前的内容及原路径记录 |
| `ai` 下的凭据文件 | Windows DPAPI CurrentUser 加密的令牌和 API Key |

会话采用有序写入及独立恢复日志。备份或迁移会话时须同时保留 `ai/projects` 和 `ai/attachments`；路径引用还依赖原始文件位置。新版附加信息为旧版转存保留冗余映射，但旧版无法读取新快照或实时路径；若旧版修改造成无法唯一匹配，新版会保留原始映射并停止发送，需从备份恢复或在新会话重新添加。草稿收集在本地完成；登录、模型刷新、发送及摘要请求连接服务。

## 认证与渲染实现

登录使用系统浏览器和本机回调，校验 state、PKCE S256、OIDC nonce、签名、身份和授权范围。凭据刷新通过文件锁串行化，保存采用原子替换。退出清理本机令牌并请求撤销刷新令牌，远程撤销失败会显示结果。

Responses 请求设置 `store:false` 与 `stream:true`，客户端维护历史。接收与 JSON 处理在后台完成，UI 合并更新；完整回答使用 Markdig 和原生 WPF 排版。HTML 作为文本处理，远程图片显示替代文字。

回答保存原始文本。完成渲染时先识别代码并保护 TeX 数学内容，再由 Markdig 构建语法树，按节点生成原生文字、链接、表格和公式；公式由 TeX 排版。定位和复制保留原文及公式映射。生成中暂以文本显示，结束后按相同规则解析；旧会话也在读取时解析，不改写历史。

强调采用 Markdig 的 CJK 规则，处理中文标点紧邻强调标记的情况。对标准语法未识别的一小类模型输出，也容忍结束双星前的空格，例如 `**出处： **后文`：起止双星须是同一段内的普通文字，中间不换行、不出现另一组双星；空格须紧跟 `：；，。！？、）】》」』` 中的一个字符，且恰好为一个 ASCII 空格。代码和转义标记不会作为边界；空格仍按原样显示和复制，原文偏移不变。其他空格、未闭合标记及不能确定作者意图的情况仍按字面或标准语法处理；即使符合容错条件，字面文字和作者本意也可能有歧义。`tests/TeXeed.AppTests` 的 `--ai-emphasis-only` 覆盖中文标点、空格、公式、代码、复制和书签等路径。

## 中途追问交互原型

在源码仓库中打开 `prototypes/ai-chat-v02/branching.html`，可体验选区追问、多条引用与评论、纵向会话关系、提问出处和用户书签；右键公式或图片可添加引用，双击关系图中的节点打开会话。主编辑框可以选择或粘贴图片及文件，也可选择文件夹；文件夹能否粘贴取决于浏览器是否向页面暴露目录。原型使用本地示例 SVG 展示已提供的公式，大型公式及其他无法提供 SVG 的公式回退到编号或附近文字，图片引用显示 alt 或前后文字。原型保存每个会话的滚动位置，以便再次打开时恢复视口，但不据此记录或推断阅读进度。

原型使用预设答复，不连接 AI；示例会话、附件与草稿保存在浏览器独立存储中，不读取或修改其他原型及原生程序中的会话，附件大小受浏览器存储容量限制。

原生编辑框的加号区分「上传文件」「引用文件」「引用文件夹」，也可粘贴剪贴板中的图片、文件和文件夹。在编辑框输入 `@` 可从项目路径候选中选择文件或目录，Enter／Tab 确认、Esc 关闭；删除插入的引用文字会移除对应路径引用。文中选区引用与附件分别收纳。上传支持常见文本、PNG、JPEG、WebP、GIF 和 PDF，添加时将内容保存为独立的不可变快照；旧版 Base64 快照继续保留。空文件和不支持的类型会被跳过并提示。文件及文件夹路径引用读取的是当前磁盘内容，原路径被修改、删除或移动后结果随之变化；空文件夹也可引用。文件夹路径以斜杠结尾，长路径省略中间而保留首尾，悬停可查看完整路径。会话与草稿保留所选快照或路径引用；快照文件不随会话自动删除，以免破坏其他会话及分叉。

未压缩的历史轮次会继续携带当时上传的文本、图片、PDF 和粘贴图片；压缩时文本可以进入摘要，二进制内容不会直接进入摘要。历史文件快照仍可通过工具重新读取，但已压缩的粘贴位图暂不支持通过附件工具重新读取。模型可分页列举、读取或搜索本会话及其继承路径中的文本快照和实时引用；读取只支持 UTF-8，不能解码的文件会报告失败。搜索有扫描上限，图片和 PDF 可通过媒体工具按需读取，实际受可用内存和模型服务限制；粘贴位图仍有独立大小限制。模型须检查工具返回的未处理项及限制，搜索未命中不能证明已完整核对。引用路径禁止经重解析点访问；目录改变可能影响分页结果。模型服务对多模态工具输出的实际支持尚需端到端验证。

原生程序可在已完成回答的文字选区右键选择「从所选内容追问」。追问会话保存来源和创建时截至该轮的祖先会话上下文，发送时与当前会话历史一起传给 AI；项目文件仍由各会话共享。原回答在来源选区末尾显示行内 🗨️ 链接，后续正文自然向后排；复制正文不会包含链接。追问会话可返回并定位来源：只展开该位置所在章节及必要的上级，其他章节维持已有折叠状态；来源尽量居中，靠近头尾时受可滚动范围限制。会话关系使用纵向节点和有向连线，双击节点打开。旧会话无分叉数据时仍可照常读取。来源文本无法消歧或内容变化时，回源可能失败并显示提示。

新建追问时，来源立即出现在新会话的引用列表中，暂不可删除；发送后保留但取消勾选，需要再次携带时可重新勾选。公式引用在发送中及完成后按公式呈现。回答阅读区、追问链接及源码编辑器优先使用离线 Noto Emoji，缺字回退 Twemoji；普通标签和输入框中的 emoji 仍由系统显示。

点击「会话关系」会打开工作区标签，显示当前会话及其关联会话。同一栏一次只显示一个标签的内容，单独分栏的 PDF 仍可阅读。切回 PDF 时保留原页码和缩放。重新激活关系标签时会更新会话关系。上游按钮返回来源，下游按钮供选择直接追问。目前连线依据追问产生的来源关系，图的布局允许含环或多重来源的数据；程序尚不支持从其他会话主动添加引用。空白新会话最多保留一个，新建时优先复用。打开项目时检查重复的空白新会话，保留含草稿、引用、书签、亲缘关系、非默认设置或未知数据的会话；清理前备份原文件。检测到其他 TeXeed 进程或备份失败时跳过清理，其他版本未使用跨进程锁，启动时仍有竞态，应先关闭旧实例。
