# 编辑器与工作区

## 打开与编辑

首页提供打开、新建、最近项目和 LaTeX 教程。最近项目支持多选删除记录，项目文件保留；窄窗口通过底部按钮切换最近项目与教程。

打开主 `.tex` 文件后，自动载入静态依赖、文献与样式文件。编辑器提供语法高亮、补全、注释、缩进、格式化、查找替换、多光标和矩形选区。格式化调整结构缩进并保留注释与 verbatim 类环境。自动换行通过“视图”菜单或 Alt+Z 切换。

Ctrl+S 保存全部修改并编译。实时预览合并连续编辑请求，编译期间继续编辑会安排下一次更新；失败时保留最近成功的 PDF。编译问题可以点击定位，完整日志可展开。

## 标签与侧栏

源码、PDF 和 AI 标签可排序、跨栏拖动；拖到文档区边缘可以拆分为两栏。源码移栏保留文档、撤销、选区和滚动位置。源码及 AI 标签支持中键关闭，源码标签另支持批量关闭；已关闭源码的本次会话修改仍参与保存。

左侧图标轨道切换大纲、文件、搜索、书签、标签与引用、待办。双击轨道空白展开或收起侧栏，再次展开恢复栏目、宽度及搜索状态。

- 大纲按层级折叠，单击展开或收起、双击定位，方向键浏览、Enter 跳转。编辑和切换侧栏保留折叠状态。长标题省略，按住标题可横向查看全文。
- 文件目录显示项目中的磁盘条目，按需展开；文件名搜索保留所属目录。拖入“优先显示”或通过右键加入，排序随项目保存。重命名保留打开文档的编辑状态。
- 书签读取显式 PDF 书签；标签显示引用锚点。两者分别搜索和导航。
- 全文搜索、文件名搜索与书签搜索独立保留输入。待办列出 TODO/FIXME。

只有 PDF 可见且预览仍对应当前成功编译结果时，大纲直接定位 PDF；其余情况下定位源码并应用当前跟随模式。

## PDF 阅读

预览设置提供“不跟随”“跟随光标”“跟随视图”。跟随光标将目标居中；跟随视图按编辑区可见内容定位。Ctrl+J 可手动定位，PDF 上右键双击或 Ctrl+左键返回源码。

当单栏前台是预览时，将预览拖到边缘拆出第二栏会保留两边当前位置；在编辑区放置光标或从预览反向定位后，恢复相应的定位行为。长代码、算法和表格优先使用块内 SyncTeX 位置；缺少部分行的位置时，在同页的有效锚点之间近似。TikZ、picture、pspicture 图形若内部位置重合，则在图形边界内按源码顺序估算，源码顺序与画面顺序不同时可能有偏差。外部 EPS 不携带其绘图源码的 SyncTeX 对应关系，只能定位到引入图形的位置。

Ctrl+滚轮以鼠标位置缩放，适合宽度和窗口调整保留阅读中心。新分辨率就绪前继续显示已有页面。裁边、纵向空白压缩和深色配色只影响阅读显示；具体算法见 [PDF 裁边](pdf-cropping.md)。打印入口见 [PDF 打印](pdf-printing.md)。

## 窗口与主题

宽窗口显示菜单和项目名，窄窗口使用菜单按钮。窗口支持原生拖动、缩放、最大化和系统菜单。F11 切换全屏；全屏中按 Alt 显示标题栏，Esc 收起。

“视图 → 主题”提供 Ristretto 和 GitHub Light Default。自定义主题及颜色字段见 [主题说明](../src/TeXeed.App/Themes/README.md)。界面显示文件名、路径和标题的原文。代码使用等宽字体，其余阅读文字遵循 [排版约定](ui-layout-and-performance.md)。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开项目 | Ctrl+O |
| 保存全部并编译 | Ctrl+S |
| 编译 | Ctrl+Enter |
| 打印与预览 | Ctrl+P |
| 关闭当前源码标签 | Ctrl+F4 |
| 自动换行 | Alt+Z |
| 全屏 | F11 |
| 补全 | Ctrl+Space |
| 注释 / 取消注释 | Ctrl+/ |
| 缩进 / 取消缩进 | Tab / Shift+Tab |
| 格式化 | Ctrl+Shift+F |
| 查找 / 替换 | Ctrl+F / Ctrl+H |
| 添加光标 | Alt+左键 |
| 矩形选择 | Alt+左键拖动 / 中键拖动 |
| 源码定位 PDF | Ctrl+J |
| PDF 定位源码 | 右键双击 / Ctrl+左键 |
| PDF 缩放 | Ctrl+滚轮 |
| AI 菜单 | Alt+A |

AI 编辑框与批注框的 Ctrl+Enter 分别用于发送和确认，见 [AI 批注](ai-annotations.md)。
