# 引用与附件分离性能（2026-11-11）

在同一 Windows 机器、.NET 10、900×760 DIP 的 WPF 窗口进行各一批前后测量。修改前为已发布 0.4.6，DLL SHA-256 `3A5F4E471EBE75606EE2072A4C4B3A608426268ABD49DD8EA029111AB7F3676F`；修改后为版本号和提交前的功能构建 DLL `3467E8E2ABE5B5B2D38DB53FCAD9E8DC35B63273D68AB88563951A8C8BCB53A8`，正式发布二进制未测。两版依次运行，没有交错复测，采样噪声和后台进程可能影响结果；只统计 UI 线程托管分配，不含 GPU 与真实输入法。

## 120 轮常规会话

`panel-fixture.cs.txt` 是既有 `graph-canvas-20261111/panel-fixture.cs.txt` 同哈希夹具，每轮含 3 条各 200 行过程记录；输入、变宽、滚动和编辑框高度均预热 2 次、记录 7 次，每次配对扣除相邻空 ApplicationIdle、800 ms 等待及保存锁。历史最佳来自同一夹具以前归档的最小值；历史版本没有后来的书签和导航等功能，功能成本与可避免开销尚未完全拆分。表格为分配中位数、配对耗时中位数：

## 含 31 文件夹的列表

`list-fixture.cs.txt` 模拟一条文字引用及一个保存 31 个合成文件快照的文件夹；测量弹窗打开而非文件读取或 AI 发送。每项预热 2 次、测 7 次，配对扣除相邻 ApplicationIdle。Popup 控件只计算相交并穿过滚动视口裁剪的控件，主窗口控件单独列示。由于旧版将引用、文件夹内容显示在同一弹窗，新版分别打开两面板，功能与展示内容不同，不将其当成相同功能的直接速度排名。

## 浏览器原型

Chrome 157、1000×820、120 轮，原型的输入/滚动与旧版 `HEAD`、归档历史夹具相同；预热 2 次、7 次，两帧及 220 ms 配对等待，CDP V8 1024 B 采样估计。输入同步中位前后均约 0.1 ms，滚动约 0–0.1 ms；采样量有负值，不能视为真实负分配或判断细微差额。可见控件约 12→13（新增附件入口），DOM 节点 1,184→1,190。历史同夹具候选 cf7cb23 为输入约 0.1 ms、滚动约 0 ms；旧版缺少后续 UI。`prototype-core.json` 保存资源哈希和结果。

`prototype-folder.cjs` 以 120 轮、一条引用与同目录 31 文件测状态恢复：同步中位 14.7→13.3 ms，采样约 294→290 KB；旧版页面内逐文件显示控件估算 43，新版收纳后 13。新版附件弹窗打开约 4.4 ms / 8.4 KB，引用弹窗约 4.1 ms / 2.1 KB；旧版无同操作基准。此脚本控件计数仅检查元素自身可见与视口，不完整检查祖先裁剪；旧、新 DOM 和交互有别，只是估算。`prototype-folder.json` 保存各次采样及资源哈希。所有浏览器结果均为单批 V8 采样，不覆盖完整 DOM、图形进程和真实系统剪贴板。

## 复测

从对应发布目录取得 TeXeed 和 TeXeed.Core 及依赖，分别以 `panel-fixture.cs.txt` 和 `list-fixture.cs.txt` 编译 .NET 10 Windows WPF WinExe，引用相应程序集；测试路径必须隔离 TEXEED_HOME，并在同一桌面环境串行运行。`panel-fixture` SHA-256 `A52DB958492CAF50D84BAC50BEE5131F98CEEDF093C490392A8C56D91099C95D`，`list-fixture` SHA-256 `495720653048D7AD2B4D931AA58455D294884A7B708FA0EC8F4A00085007C34C`。浏览器从仓库根设置 `TEXEED_PLAYWRIGHT_PATH` 和 `TEXEED_BROWSER_PATH`；`prototype-core.cjs` 额外设置 `TEXEED_PERF_BASELINE=HEAD`、`TEXEED_PERF_MODES=before,after`、`TEXEED_PERF_ROUNDS=1`，`prototype-folder.cjs` 使用当前 HEAD 的原型归档与工作树原型。测量时 HEAD 为修改前 0.4.6，原型三文件哈希分别保存于 JSON；若以后 HEAD 改变，应将脚本中的 HEAD 替换为当时 commit。性能测试未覆盖真实系统剪贴板或发布后二进制，不以这些单批数字宣称整体性能全面通过。
