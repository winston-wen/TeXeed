# 深色强调与批注提示性能（2026-11-18）

本机、.NET WindowsDesktop 10.0.7、Ristretto，屏幕外不激活 WPF 窗口、隔离项目与 `TEXEED_HOME`。正式 0.5.10 与 0.5.11 提交前功能构建均各测一批；正式发布程序集因嵌入提交信息而不同，未重复采样。逐次样本与程序集、宿主及夹具 SHA-256 见本目录 JSON。各项两次预热、七对测量；排队延迟、草稿保存锁与 ApplicationIdle 的同条件空等待配对扣除。单批及负校正结果不足以判断微小耗时差。

普通 120 轮夹具使用 `../queue-handoff-20261117/panel-offscreen.cs.txt`，包括三条各 200 行过程记录；每次等待 800 ms 并扣除保存锁。历史可复核最佳分配输入／变宽／滚动／输入框高度分别为 253,864／550,296／176,328／108,584 B、40 个可见控件；历史窗口可见、运行环境不同且缺少后续功能，不能作为本次同环境结论。改前／本次分配为 262,032／262,032、848,184／853,544、190,144／190,184、116,048／116,048 B，均 47 控件；即时反馈分别为 3.92／3.65、20.72／23.73、1.03／1.30、3.46／3.73 ms，校正耗时为 0.44／−0.72、23.29／18.96、−2.27／2.04、−2.61／2.04 ms。各一批，变宽和滚动的少量分配差异未证明稳定，历史差额包含既有功能与未分离的实现成本。

`bold-fixture.cs.txt` 使用独立 Markdown 阅读视图、60 段中文和每段两处加粗，测试替换正文后的重排与窗口变宽；每对配对等待 250 ms。0.5.10／0.5.11 分配中位为重排 4,824,216／4,824,216 B、变宽 2,890,848／2,890,848 B，均 2 个可见控件；即时反馈为 31.03／31.31、24.37／23.55 ms，校正耗时 32.80／32.78、27.94／16.20 ms。没有同场景更早可复核基线，各一批不足以推断微小耗时变化。

`mark-mode-fixture.cs.txt` 在相同 120 轮会话中测进入／退出回答批注模式，配对等待 800 ms；改前／本次分配 32,720／33,112、26,880／28,184 B，即时反馈 1.48／1.64、1.09／1.13 ms，校正耗时 0.64／0.92、4.11／1.48 ms，均 47 控件。退出后一开始两版均显示提示并占 14.63 DIP；此项仅覆盖前 800 ms，不能用来计算 3 秒回调的完整成本。

`mark-exit-complete-fixture.cs.txt` 在相同 120 轮会话中单独测退出，配对等待 3.5 秒并扣除保存锁，计入提示回收与布局；七次采样窗口始终可见且均 47 控件。旧／新即时反馈中位为 1.08／1.17 ms，配对校正耗时 1.58／2.75 ms，UI 分配 16,768／35,432 B。旧版 3.5 秒后提示仍占 14.63 DIP，新版提示为空、高度 0。稳定多约 18.7 KB，包含一次性计时、提示消失及布局等功能差异；无调用栈或同功能反事实，尚不能拆分必要成本与可避免开销，性能验收未全面通过。

最初的 `invalid-before-exit-user-closed.json` 采样期间窗口被关闭，后四次控件数为 0，已作废且不用于以上结果。有效的 `*-exit-complete.json` 使用不显示任务栏的屏幕外窗口，并验证每次窗口仍可见。每组测量无真实鼠标、GPU 或真实 AI 请求；只统计 UI 线程分配，后台工作未计入。
