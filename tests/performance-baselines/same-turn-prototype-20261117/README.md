# 同会话轮次链接原型性能

使用 `measure.cjs` 的固定夹具：120 轮、60 条可以定位的本会话引用，以及末尾 10 条公式引文；三批交错历史 `7af94c2`、修改前 0.5.4 `bba3359`、最终原型。相同状态输入各版本，只有本版实际显示 60 个链接；历史版本还没有正确渲染引文公式。每版每批预热两次、记录七对，包含两帧、700 ms 等待与配对空操作校正，V8 采样间隔 1024 B。`samples.json` 保存全部配对、资源指纹、环境和结果，采样分配是估计而不是总分配。环境为 Windows `10.0.26300`、Ryzen 7 5700X、Node `v24.22.1`、Chrome `157.0.8103.79`、1000×820。

| 操作 | 历史 | 修改前 | 本版 |
| --- | --- | --- | --- |
| 输入同步时间 | 1.2–1.6 ms | 1.3–1.4 ms | 1.4 ms |
| 输入净采样分配 | 163–175 KB | 171–179 KB | 170–180 KB |
| 滚动同步时间 | 0–0.1 ms | 0–0.1 ms | 0–0.1 ms |
| 滚动净采样分配 | 168–179 KB | 180–183 KB | 185–188 KB |
| 重绘同步时间 | 21.0–41.2 ms | 29.3–30.6 ms | 32.3–38.3 ms |
| 重绘净采样分配 | 1.161–1.186 MB | 1.045–1.075 MB | 1.145–1.153 MB |

按各项分别选取，本次同环境历史最佳输入／滚动／重绘同步时间为 1.2／0／21.0 ms，净采样分配为 163,014／167,971／1,044,841 B，分别来自不同版本及批次。历史版重绘有 41.2 ms 的慢批，且仅 2,733 个 DOM 节点、11 个可见控件；0.5.4 为 3,927／18。本版为 3,987 个节点、60 个链接；输入场景 20 个可见控件，滚动和重绘场景 18 个。节点和可见控件按各操作当时视口统计。

本版重绘比改前三批分别增加约 78、80、103 KB 净采样分配，并增加 60 个链接节点；这包含新增功能的成本，反复创建节点、遍历语法位置等实现开销也可能贡献其中，尚未分离。重绘时间较同场景历史最佳仍高，但版本功能不同且历史慢批明显，不据此把全部差距判为退化。滚动分配三批比改前分别增加约 4.8、1.7、6.4 KB，采样波动和实现开销尚未分离。输入差异较小。两帧及等待后的校正中位数分批保存在原始样本中，受调度影响会出现负值。

目标已展开时，交替点击首尾链接并确认目标进入视口：本版同步时间 1.3–1.4 ms，净采样分配 361–372 KB，等待校正 0.2–6.1 ms，22 个可见控件。旧版本无此功能，不能直接比较。早期实现每次点击会重绘完整历史，一次未完成的对照观察为 34.3 ms／约 1.52 MB；它只有输出摘要、没有完整配对，保存在 `interrupted-summary.json`，不当作可复核历史最佳。最终代码对展开的目标直接定位；折叠目标仍需展开，未包含在导航性能采样里。

复测时设置 `TEXEED_PLAYWRIGHT_PATH`、`TEXEED_BROWSER_PATH`、`TEXEED_PERF_BASELINE=bba3359`、`TEXEED_PERF_ROUNDS=3`，运行 `node tests/performance-baselines/same-turn-prototype-20261117/measure.cjs artifacts/same-turn-links-prototype-final.json`。它使用合成数据和程序触发的点击，不代表物理鼠标或真实 AI 请求。
