# AI 回答菜单、浮窗和表格交互性能

2026-11-17 在 Windows 10.0.26300、Ryzen 7 5700X、Node 24.22.1、Chrome 157.0.8103.79、1000×820 视口下，比较历史提交 `7af94c2`、本轮修改前 `44204da` 与本轮源码。脚本将历史版本从 Git 取出，并在 `artifacts/` 自建临时副本，不读取未提交的临时夹具。JSON 含运行环境、脚本及实际加载资源的 SHA-256、每项七对原始样本、节点数量及内存采样；各测试先预热两次。时间含双帧及 700 ms 后续等待，配对空操作作排队校正，V8 以 1024 B 间隔采样，分配量是估计值。脚本按单项及时写出样本。

`measure.cjs` 用 120 轮同一数据测右键菜单、打开并关闭批注浮窗、表格单元格点击。菜单及浮窗由脚本触发，表格使用 Playwright 的真实浏览器鼠标事件；所记同步耗时包含浏览器驱动往返，不能当成纯函数执行时间。首批的当前／修改前同步中位数依次为 1.4／1.6、3.3／3.5、18.2／18.5 ms；校正中位数为 17.2／19.7、17.5／18.7、35.9／34.0 ms。当前与历史比较未同时超过 30% 和 8 ms。当前菜单采样分配约 4.4 KB，修改前约 0.2 KB，历史约 3.5 KB；单批差异未归因，不能判断是否稳定。当前浮窗及表格分配小于本批修改前。菜单打开时当前可见控件 25、改前 22、历史 16；数据和功能不完全相同。原始数据为 `interaction-samples.json`。

`measure-reading.cjs` 沿用 120 轮、60 条本会话追问链接和 10 条公式引文夹具。修改前和当前版都有链接，历史版没有链接和正确的公式引文，不能将功能成本直接算成实现退化。当前／修改前重绘同步中位数为 34.3／34.6 ms，净采样分配约 1.156／1.144 MB；输入、滚动和已展开目标导航与修改前接近。数据为 `reading-samples.json`。此前的三批及历史条件保存在 `../same-turn-prototype-20261117/`，不能因旧版功能较少而排除历史最佳。

重绘超过历史基准后，`measure-render.cjs` 仅对重绘增加两批正反序交错复测。历史／修改前／当前同步时间分别为 22.5/18.3、31.8/29.5、40.7/32.3 ms；排队校正分别为 14.3/13.9、32.5/30.3、43.7/42.0 ms。历史同夹具可复核同步最佳为 18.3 ms。当前较修改前的校正增量为 11.2/11.7 ms，两批均同时超过 30% 和 8 ms；采样分配在首批及复测中比修改前分别高约 12、26、11 KB。采样分配存在稳定正增量，但具体原因未分离。性能简评未通过，数据为 `render-deep-samples.json`。

`measure-css-counterfactual.cjs` 在临时副本中分别还原本轮样式、或在初始化后移除三个新增的隐藏菜单及提示节点；当前代码与 60 链接夹具不变。两批交错的排队校正中位数，样式回退为 33.1/31.6 ms，移除节点为 29.3/28.7 ms，当前为 34.4/29.0 ms。当前较样式回退的采样分配高约 8.7/19.9 KB，较移除节点高约 17.0/4.6 KB；时间差两批不一致，不能确定这些因素就是此前增量的原因。该反事实改变了用户可见功能，仅用于定位，不作为交付实现。样本为 `counterfactual-samples.json`。

代码核查发现：有轮次时，重绘不进入新加的空会话来源预览分支；菜单、拖动和表格事件监听器在初始化时注册，并非每轮重绘时重绑。现有重绘仍重建全历史并重新放置 60 条追问链接，是功能相关的既有开销；尚未证明本轮多出的分配或校正时间来自此处。没有已验证的简单修复，因此保留警报。

最初启动三批时在第一批中途按要求终止：只有菜单、浮窗、表格的历史和修改前摘要以及当前菜单摘要，没有完整原始配对，不作为基准；随后重新运行并保存本目录完整样本。

复测时设置 `TEXEED_PLAYWRIGHT_PATH` 和 `TEXEED_BROWSER_PATH` 指向 Playwright 及 Chrome；依次运行目录下 `measure.cjs`、`measure-reading.cjs`、`measure-render.cjs`、`measure-css-counterfactual.cjs`。每次均传入一个不同的 JSON 输出路径，以免覆盖样本；不带输出路径的脚本默认文件名并不互相区分。`TEXEED_PERF_ROUNDS=1` 用于首批，后两项用 `2`；`TEXEED_PERF_BASELINE=44204da`。源码和依赖指纹须与样本核对后再比较；结果不代表真实 AI 网络请求或原生 WPF 窗口。
