# 会话关系标签与历史刷新性能（2026-11-11）

同机 WPF 900×760 DIP，120 轮会话、每轮 3 项各 200 行过程记录，输入、窗口宽度、阅读区滚动和编辑框高度各预热 2 次采 7 次；每次包含 800 ms 延迟保存，并扣除相邻 ApplicationIdle 与空等待的排队耗时及 UI 线程分配。可见控件数仅按控件窗口相交估算。修改前为已发布 0.4.4，DLL SHA-256 `0399CF28DF370ADDC12170848F220C1431CB39214E2E33511A32A3D1B80C9913`；修改后为功能构建 DLL `538B2E01A25BCDA1F3680DE04313C1A203883041AC38C7A42BE8EDEBF66AC66F`，最终发布重新构建后二进制未测。各版本各 1 批，按前后顺序而非交错运行，不能将一次差额判为稳定回归。旧版不含两个上下游导航按钮。实测时 `fixture.cs.txt` 的 SHA-256 为 `5D998DDBA4B701F9B459F2A7A272883784FD345576B59B82107B6410CDAC6912`；入库时仅规范化文件末尾空行，现存文件 SHA-256 为 `A52DB958492CAF50D84BAC50BEE5131F98CEEDF093C490392A8C56D91099C95D`；`before.json`、`after-rebuild.json` 保存原始采样。`after.json` 及不带 rebuild 后缀的修改后图、归因样本为先前增量构建误带旧刷新图标 BAML 的样本，保留但不作为最终结论。

历史最佳分配取 `context-branch-ui-20261110/native-historic.json` 与 `native-after.json` 等相同夹具的最小中位，缺少之后的书签和导航等功能。历史候选的配对耗时中位：输入最低约 0.25 ms、变宽约 14.73 ms；滚动及高度出现负值（约 -0.97 和 -2.00 ms），无法判定真实历史最佳耗时。由于 800 ms 配对等待引入抖动，表中负值和数毫秒差异不可解释为真实耗时或稳定排名；保留即时反馈时间在各 JSON。新增 2 个可见控件为上游、下游按钮。变宽增加 13,200 B：同一功能 DLL 同一夹具隐藏这两个按钮与显示两按钮各一批分别为 562,808／575,960 B，差 13,152 B（可见控件 42／44），提示差额与新增控件及布局相关；隐藏按钮也改变了布局，尚无调用栈，不能断言全部属于不可避免的功能成本。`resize-hidden-rebuild.json`、`resize-visible-rebuild.json` 与 `resize-fixture.cs.txt` 保存此深评；需要多批交错后才能判断稳定性。

另用 `graph-history-fixture.cs.txt` 在真实 MainWindow 中构建 60 个相关会话，预热 2 次采 7 次并扣除相邻 ApplicationIdle：旧版打开关系弹窗／新版打开关系标签配对分配中位 3,479,080／4,271,240 B，耗时 87.77／44.68 ms，可见控件 25／58；两次操作的展示方式和被计数的窗口不同，差额包含整个工作区，不是同一功能成本。`graph-history-before.json`、`graph-history-after-rebuild.json` 含原始样本；首次图测试单独的 `graph-before`／`graph-after` 未纳入最终结果。历史页 61 条会话上点击刷新，配对分配 594,688／618,496 B，耗时 11.08／9.51 ms，可见控件均 58；旧版为图标，新版为文字，仅各一批，不能判定 +23,808 B 是否稳定或仅由字形造成。没有找到同场景更早历史最佳，旧版为可复核暂定基准。没有测真实鼠标输入、GPU、物理设备、最终发布二进制，不能称整体性能全面通过。

复测时将夹具编译为 .NET 10 Windows WPF WinExe，引用对应 TeXeed、TeXeed.Core 程序集并复制对应版本运行依赖；使用独立 `TEXEED_HOME` 与新结果目录、串行运行，避免加载真实会话。关系图夹具在旧版调用现有弹窗入口，新版调用 MainWindow 的关系标签入口；窗口内容、图树项和控件总数随功能不同。刷新夹具调用实际历史页刷新按钮的 WPF Click 事件。数值为 CPU UI 线程托管分配，未测非托管和 GPU 内存。
