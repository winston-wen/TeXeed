`samples.json` 保存本次同机同场景历史版、修改前和修改后的全部样本及加载资源指纹。使用 `quote-scrollbar-prototype-20261116/measure.cjs`，`TEXEED_PERF_BASELINE=d5d646277bf9760485e9ded60dc840e02fcf1f54`。合成场景为 120 轮、10 条公式引文，1000×820，预热两次、测七对，记录同步时间、两帧及 700 ms 排队校正、V8 采样分配和可见控件。采样分配是估计，不是总分配；校正结果可能因排队噪声为负。

历史最佳按各项分别选取，可能来自不同版本：输入时间及重绘分配取修改前，输入与滚动分配及重绘时间取 `7af94c2` 历史版。历史版没有正确渲染公式引文，只有 2,733 个 DOM 节点和 11 个可见控件；修改前后均为 3,927 个节点和 18 个可见控件。修改前后重绘增加 1.6 ms、净采样分配增加约 11 KB；滚动分配增加约 5.4 KB。仅一轮且采样有波动，不能断定这些增量稳定，也不能从旧版较快推断全部差异是退化。本夹具以缓存引文为主，不代表大量不同的中文强调文本。

本次环境：Windows `10.0.26300`、Ryzen 7 5700X、Node `v24.22.1`、Chrome `157.0.8103.79`，视口 1000×820。此前 `quote-scrollbar-prototype-20261116/samples.json` 记录的 Windows、CPU、Node 和视口相同，Chrome 为 `157.0.8103.51`；两批都未记录启动时间，无法证明是否跨系统重启。先前使用 `measure-sampled.cjs`，本次使用 `measure.cjs`，两者唯一代码差异是确定修改前 Git 提交的方式；场景和采样方法相同。由于浏览器版本不同，此前样本单列参考，不混入上述同环境最佳。此前记录的输入／滚动／重绘最佳同步时间分别为 1.1／0／21.4 ms，最佳采样分配分别为 142,518／148,524／1,059,385 B；各项也可能来自不同版本。完整版本、资源哈希和样本见该目录的 `samples.json`。

## 三批交错深评

同一浏览器与场景，以历史 `7af94c2`、修改前 0.5.4 `bba3359` 和包含同会话链接的最终原型交错三批，每版每批各预热两次、记录七对；完整配对、资源指纹和环境见 `deep-samples.json`。输入同步中位数三版范围为 1.0–1.2／1.0–1.6／1.2–1.3 ms，净采样分配为 143,592–143,646／144,985–149,473／144,997–150,990 B；滚动时间为 0／0–0.1／0.1 ms，分配为 149,654–155,449／156,142–163,809／154,297–156,453 B。实际可见控件为 11／18／18。

重绘同步中位数为 21.3–24.2／26.4–37.6／27.9–31.6 ms，净采样分配为 1,161,478–1,189,490／1,059,109–1,073,626／1,066,340–1,086,185 B。先前同环境单批历史最佳为 19.9 ms，本次各批仍高于它；历史缺少公式引文、节点数及控件更少，这一功能差异不能将全部时间差归为实现退化。同功能改前两批达 37 ms，较本次更高，时间波动明显；本次三批采样分配均高于对应改前约 7–19 KB，单次采样误差及新增解析／链接机制成本尚未分离。该旧夹具没有实际创建同会话链接，因此不覆盖新增链接的节点、渲染及定位成本。

复测命令与上一节相同，另设 `TEXEED_PERF_BASELINE=bba3359`、`TEXEED_PERF_ROUNDS=3`。中途因转向其他功能而停止的一次尝试仅保存了第一版摘要，见 `interrupted-deep-summary.json`；它不是完整的三版对照，不用于以上结论。
