# AI 阅读字重与公式、追问气泡中轴性能（2026-11-19）

同机使用 Windows 10.0.26300、WindowsDesktop 10.0.7。每版 Release 程序与相同夹具在独立配置中运行，WPF 窗口置于屏幕外且不激活，尺寸为 900×760 DIP 或 620×760 DIP。每项两次预热、七对样本。首轮反馈计至 ApplicationIdle，随后纳入公式任务、800 ms 空闲和适用的异步保存，与配对空操作校正 UI 线程分配及耗时。可见控件按与窗口相交估算，未完全扣除祖先裁剪。单批调度有波动，负校正值表示差值落在调度波动内。

- [120 轮夹具](../manual-form-unlock-20261118/panel-fixture.cs.txt) 测试输入、变宽、滚动与主编辑框增高。同机复测了 [既有历史构建](../chat-viewport-20261119/README.md)，其功能范围有差异。
- [长回答标题夹具](../chat-font-size-20261119/fixture.cs.txt) 实际折叠并展开 24 个标题之一，再交替改变窗口宽度。0.5.15 和 0.5.17 保留了原版源码与已发布程序集。
- [混排夹具](fixture.cs.txt) 含 30 个中英文文本块、五个标题、90 个行内公式与一个行间公式。公式使用合成 SVG 热缓存。重排交替切换段末文字，交替宽度及替换追问使用四个通过真实锚点插入的气泡，其中一个在标题中。替换操作保留总链接数。夹具无 AI 网络请求、公式冷编译、真实鼠标或 GPU 测量。

## 混排开销对照

以下为正式 0.5.17 与纳入两项优化后的 0.5.18 功能构建。0.5.17 是当前夹具最早的可比样本。

| 操作 | UI 线程分配 | 首次反馈 | 排队校正耗时 | 可见控件 |
| --- | --- | --- | --- | --- |
| 混排重排 | 7,256,368／7,244,216 B | 34.92／31.58 ms | 32.18／31.92 ms | 2／2 |
| 混排窗口交替变宽 | 5,415,000／5,422,320 B | 32.54／30.33 ms | 32.67／28.16 ms | 6／6 |
| 替换一个追问气泡 | 308,864／341,536 B | 3.75／3.66 ms | 0.38／−0.77 ms | 6／6 |

均保留 91 个公式控件。最终重排分配接近改前，变宽分配中位多 7,320 B，主要集中在窄窗样本。替换一个气泡仍多约 33 KB，各样本均增加。剩余差额包含新的字形测量及内联排版，未采调用栈，仍无法区分不可避免的功能成本和其余可避免开销。 [最终逐次样本](final-mixed.json)

原生专项首次通过时，混排重排分配由 7,256,368 增至 7,678,040 B，替换一个气泡由 308,864 增至 461,312 B。试验保留新的字形轴和 18 DIP 公式，每个阅读控件至多复用 64 个字形样本的测量结果，字号或字体改变时清空。重排回到 7,244,216 B，较初版少 433,824 B。原始样本见 `before-mixed.json`、`after-mixed.json`、`cache-mixed.json`。

另一次单独对比在插入追问控件前计算其基线。初版在控件测量中设置基线，会触发额外的文档测量；预计算后，替换气泡的分配为 348,576 B，减少 112,736 B（初始增量的约 74%），首次反馈由 5.59 回到 3.76 ms。两次都实际保留四个气泡及同一对齐结果。原始样本见 `optimized-mixed.json`。

在首次候选中只把 `MarkdownView` 的行内和行间公式还原到 16 DIP，保留新的轴计算和气泡布局，重排／变宽分配为 7,676,576／5,423,048 B，接近原候选的 7,678,040／5,423,880 B。这组固定文本的增量主要可由轴计算与布局解释，把公式缩回去对该夹具的分配影响很小。更长公式跨过折行阈值的工作量在此次夹具中未单独量化。 [仅改变公式字号的样本](size-mixed.json)

## 绘制核验

[原生专项](../../TeXeed.AppTests/AiInlineTypographyTests.cs) 独立读取 WPF 字形绘制、LaTeX SVG 路径和追问图像的可见位置。0.5.17 的公式实际为 16 DIP，标题及正文的数学中轴比字形中轴低约 2.9 DIP，标题气泡低约 2.86 DIP。候选在两种主题及 440 DIP 窄窗中测得 18 DIP，等号样例的两个中轴差小于 0.001 DIP，标题及正文气泡差 0.071／0.027 DIP。测试单独验证了窄窗下行间公式重新排布。 [浏览器原型复测](browser.md)

## 复测

使用 [WPF 测量宿主](../annotation-modes-20261118/Harness.csproj) 以 Release 编译。将 `ProductDir` 指向该版本完整程序目录，`Fixture` 指向相应夹具绝对路径。将宿主的 `TeXeed.AppTests*` 复制到各被测程序的独立完整副本。核对 `fingerprints.json`，执行 `dotnet TeXeed.AppTests.dll <独立输出目录>`。混排夹具还需传入 [合成 SVG 目录](../quote-scroll-20261116/math-svg/) 的绝对路径。
