# 填写控件与追问原型性能（2026-11-12）

同机 Edge 157、1000×820，沿用 `inline-return-20261112` 的 120 轮、60 条追问及折叠章节夹具。历史 `cf7cb23`、改前 `a07ec4c`、本次原型各一批，每项预热两次并采七对操作与空操作，均计入两帧与 220 ms 等待；CDP 以 1024 B 采样分配。原始数据、资源和脚本指纹见 `results.json`。运行 `measure.cjs` 时设置 `TEXEED_PLAYWRIGHT_PATH`、`TEXEED_BROWSER_PATH`，输出路径作为首个参数。

新来源返回、旧来源返回及章节展开的同步中位：历史 3.3／3.2／0.4 ms，改前 3.4／2.3／0.6 ms，最终原型 2.2／2.2／0.5 ms。配对采样分配分别约 315,568／300,456／110,720 B、300,312／312,152／106,688 B、308,296／296,588／108,628 B；可见控件数依次为 7 或 6、18、19。最终资源包含表单、附件、判题和追问 Noto 图标，结果见 `final.json`；历史和改前取 `results.json`，没有与最终资源交错测量。配对耗时受调度影响且出现负数，单批和 V8 采样不足以判定小幅变化的稳定性。历史版缺少后来功能，差异包含功能与未分离的实现成本。

单独的 `measure-forms.cjs` 在 120 轮后追加填写示例，配对测输入事件与 220 ms 等待；同步中位 0.1 ms、净采样 3,092 B，配对耗时中位 1.0 ms（调度波动），可见控件按视口矩形估计 30 个。逐次结果在 `form-input.json`，原型每次输入单独保存当前表单草稿，不序列化整段会话。旧版无此功能，无法提供同功能历史比较。两个夹具均不涵盖原生 WPF、真实输入法或模型请求。
