# TeXeed 应用图标

采用用户选定的 07「绿芽＋书」：绿色嫩芽、暖白对开书与写意图文，背景透明。2026-10-14 用户确认采用三维计算稿之前的版本，替换原 05「TE 合字」；0.3.10 按要求去掉深色底板并等比例放大主体。

- `TeXeed.png`：1024×1024 透明底母版；主体约 984×797，左右各留 20 像素，上下约 113 像素。宽高使用同一缩放比例，保持原稿形状。
- `TeXeed.ico`：Windows 图标，包含 16、20、24、32、40、48、64、128、256 像素的 32 位透明帧。
- `scripts/build-icon.ps1`：从母版重新生成 ICO，只转换尺寸和文件格式。

生成说明：从候选板第 07 款演化，嫩芽改为绿色，书页加入少量线条、山形和圆点。透明版按用户明确授权用代码处理 0.3.9 原图：提取书与芽的轮廓、保留书页内深色图文、去除背景混色并等比例放大约 18%，没有重绘或拉伸主体。ICO 由母版转换尺寸与格式。带底板原图保存在 0.3.9 的 Git 提交中，历史 TE 合字母版可从 0.3.8 的 Git 提交恢复。

EXE 使用 `ApplicationIcon` 内嵌 ICO，WPF 公共窗口样式引用同一资源。Windows 任务栏身份为固定的 `TeXeed.Desktop`，与发布快捷方式保持一致。
