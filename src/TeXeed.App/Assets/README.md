# TeXeed 应用图标

采用用户选定的 07「绿芽＋书」：绿色嫩芽、暖白对开书、写意图文与暖黑圆角底。2026-10-14 用户确认采用三维计算稿之前的版本，替换原 05「TE 合字」。

- `TeXeed.png`：1024×1024 透明底母版，由内置 imagegen 根据已选方案制作；可见圆角底板为 960×960，四边留白各 32 像素。
- `TeXeed.ico`：Windows 图标，包含 16、20、24、32、40、48、64、128、256 像素的 32 位透明帧。
- `scripts/build-icon.ps1`：从母版重新生成 ICO，只转换尺寸和文件格式。

生成说明：从候选板第 07 款演化，嫩芽改为绿色，书页加入少量线条、山形和圆点，调整书与芽的位置后规范为正方形。采用已确认的原图，仅转换 ICO 尺寸与格式，不重绘构图。历史 TE 合字母版可从 0.3.8 的 Git 提交恢复。

EXE 使用 `ApplicationIcon` 内嵌 ICO，WPF 公共窗口样式引用同一资源。Windows 任务栏身份为固定的 `TeXeed.Desktop`，与发布快捷方式保持一致。
