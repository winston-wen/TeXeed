# Explorer icons

These 13 SVGs were copied unchanged from the locally installed `vscode-icons-team.vscode-icons` extension, version 13.0.0 (`icons/`). Source: https://github.com/vscode-icons/vscode-icons ; MIT license: `licenses/vscode-icons-MIT.txt` at repository root.

The subset contains default file, closed/open folder, TeX dark/light, PDF, Markdown, Git, JSON, image, text, configuration and C# icons. Run `scripts/build-explorer-icons.py` with Python 3 to regenerate `ExplorerIcons.xaml`. The app draws the shared, frozen vector resources and does not parse SVGs at runtime.
